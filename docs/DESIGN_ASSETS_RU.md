# Графика POLSKI GO

В код подключены отдельные WebP: четыре позы бобра (wave, think, celebrate, read) с прозрачностью и панорамы Warszawa, Kraków, Wrocław. Исходные изображения созданы встроенной генерацией по утверждённому листу персонажа; в проекте используются уменьшенные WebP с сохранением альфа-канала. Общий вес семи файлов около 1.1 МБ.

Задание для персонажа: один узнаваемый объёмный бобр, каштановый мех, светлая мордочка, два передних зуба, широкий клетчатый хвост, красная худи PL и зелёный рюкзак; полный рост, прозрачный фон, без текста интерфейса, подписи и рамки. Поза меняется между приветствием, размышлением, победой и чтением. Городские сцены подготовлены без персонажа, текста и кнопок: эти слои реализованы отдельно.

Подключение:
- CityHero и CityBanner используют cityAsset(slug).
- Beaver использует beaverAsset(mood) для поддержанного стартового образа.
- supportsBeaverArt допускает только соответствующую картинке одежду. Случайная шапка, костюм или аксессуар не скрываются: для неподдержанного набора сохраняется старый составной SVG.
- Из примерки убран принудительный vectorOnly для поддержанного стартового образа.
- Фоны и иконки подключены к карточкам «Быстрого старта»; заголовки и кнопки остаются элементами интерфейса.
- Nunito хранится локально в четырёх Unicode-поднаборах; лицензия находится рядом с файлами шрифта. Внешняя загрузка Google Fonts больше не требуется.

Оставшаяся работа: все выбранные пользователем кастомные вещи пока не имеют нового растрового комплекта/слоёв; они видимы в прежнем SVG. Это честное ограничение, а не полностью завершённый редизайн гардероба. Нужно подготовить совместимые слои или цельные образы для каждого поддерживаемого комплекта. Остальным городам также нужны собственные панорамы; текущая SVG-графика остаётся запасным вариантом.

Заставка сохраняет прежнюю многослойную сцену и отдельный образ без худи. Она не заменена одной картинкой.
