# Графика POLSKI GO

Растровые ассеты лежат в `apps/web/src/assets/` (WebP с альфа-каналом) и подключаются через `lib/assets.ts`
(`import.meta.glob`): отсутствующий файл не ломает экран — остаётся векторная версия.
Источник — листы «Бобёр и эмоции», «Костюмы и города», «Иконки без эмодзи», позы и панорамы, присланные владельцем;
вырезка фона — rembg (isnet-anime / u2net), правка масок вручную.

| Папка | Что есть | Вес |
|---|---|---|
| `beaver/` | 14 образов: wave, greet, think, doubt, correct, support, read, victory, celebrate, travel, front, three-quarter, side, back | ≈0.7 МБ |
| `costumes/` | Бариста, Повар, Проводник, Гном Вроцлава, Дракон Кракова, Художник, Зимний образ (+ сцена карточки у каждого), сцена «Путешественник» | ≈0.7 МБ |
| `cities/` | 18 из 20 городов: Warszawa, Kraków, Wrocław — финальные панорамы 1440×720 (WebP q74); 15 — временные кадры с досок владельца (Real-ESRGAN ×4, WebP q76); у каждого вариант `@640`. Gorzów и Gdynia — нет. Инвентарь — `docs/CITY_ART_INVENTORY.md` | ≈2.5 МБ (грузятся по требованию) |
| `icons/` | 24 иконки листа (уроки, карта, квесты, паспорт, Złotki, серия, …) | ≈0.6 МБ |
| `brand/` | Логотип POLSKI GO, аватар бобра | ≈0.07 МБ |

## Как подключено
- **Бобёр:** `BEAVER_POSES` даёт каждому состоянию свой образ (радость, мысль, сомнение, «правильно», поддержка,
  чтение, победа, праздник, путешествие, …). Растр показывается только для фирменного образа (`supportsBeaverArt`) или
  костюма целиком (`costumeArt`: без очков, шарфа, обуви, аксессуара и чужого рюкзака). Любой другой выбранный наряд
  остаётся векторным — он не подменяется картинкой. Сон, «королевский» и «музыка» — только вектор.
- **Костюмы:** карточки гардероба показывают сцену костюма; на бобре — растр костюма.
- **Города:** `CityHero`/`CityBanner` берут панораму, для остальных городов — векторный Краков из `SplashWorld.tsx`.
- **Иконки:** `GameArt`/`GameIcon` сопоставляют ключи интерфейса с иконками листа; пиктограммы картинок заданий —
  Lucide (ISC, `components/pictograms/LICENSE-lucide.txt`) и свои в том же стиле. Эмодзи в интерфейсе не выводятся.
- **Заставка:** панорама Варшавы, логотип, бобёр «привет», карточка прогресса; в `index.html` до загрузки JS
  виден тот же логотип на тёмном фоне. Векторная многослойная сцена удалена.
- **Шрифт:** Nunito локально, четыре Unicode-поднабора, лицензия рядом.

## Чего не хватает
- Растр костюма «Русалка» (`costume-syrenka`) — сейчас векторная версия.
- Панорамы Łódź, Katowice, Opole и остальных городов маршрута — сейчас векторный запасной вариант.
- Позы «сон», «королевский», «музыка» — только вектор.
- Слои одежды (шапки, очки, шарфы, обувь) для растрового бобра — при любом таком предмете бобёр векторный.
