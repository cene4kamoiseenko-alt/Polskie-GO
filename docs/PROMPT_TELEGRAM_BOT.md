POLSKI GO — полноценная реализация Telegram-бота

Продолжай разработку существующего проекта POLSKI GO.

Я прикрепил комплект изображений и подробное техническое задание POLSKI_GO_Claude_Telegram_Bot_Spec.md. Изучи их, а также текущий код проекта. Выполняй работу самостоятельно, последовательно, без использования дополнительных агентов.

Главный приоритет — Telegram-бот: команды, иллюстрации, персонализированные сообщения, кнопки и уведомления.

Этап 1. Подключение изображений

Распакуй изображения из архива в apps/web/public/bot/commands/.

Используй следующие соответствия:

Команда	Изображение
/start	start.jpg
/lesson	lesson.jpg
/map	map.jpg
/words	words.jpg
/quests	quests.jpg
/profile	profile.jpg
/settings	settings.jpg
/help	help.jpg
/stop	stop.jpg

Дополнительно подключи изображения reminder-lesson.jpg, reminder-streak.jpg, reminder-return.jpg.

Используй Telegram Bot API sendPhoto с публичным HTTPS-адресом изображения, подписью и inline_keyboard. Если фотография недоступна, отправляй обычное текстовое сообщение с теми же кнопками.

Не меняй установленную вручную картинку Description Picture в BotFather.

Этап 3. Реальные кнопки и переходы

Не создавай декоративные кнопки.

Для каждой команды реализуй настоящую Telegram inline_keyboard.

По нажатию должна открываться нужная вкладка Mini App, а не всегда стартовый экран.

Проверь маршруты в apps/web/src/App.tsx.

Если необходимо, добавь контролируемый параметр bot_screen, который будет преобразовываться в существующий маршрут React Router.

Не нарушай работу существующих startapp, реферальных ссылок, авторизации и onboarding.

Этап 4. Локализация

Все тексты должны поддерживать четыре языка:

* Русский
* Украинский
* Польский
* Английский

Выбирай язык из сохранённых настроек пользователя, иначе из языка Telegram.

Сделай качественные переводы. Польские выражения оставь в игровом стиле. Не используй машинные кальки и неграмотные конструкции.

Корректно экранируй имя пользователя и другие данные для Telegram HTML.

Этап 5. Автоматические уведомления

Переделай apps/server/src/jobs.ts.

Вместо однообразного текста бот должен присылать красивую фотографию с тематическим напоминанием.

Обычное напоминание:

«🇵🇱 Cześć! Бобек уже приготовил для тебя новый урок! 🦫📚 Найдёшь пять минут для польского?»

Кнопка: «📚 Продолжить урок».

Напоминание о серии:

«🔥 Твоя серия обучения — {streak} дней! Бобек предлагает закрепить успех небольшим уроком. 🇵🇱»

Кнопка: «🔥 Продолжить серию».

Возвращение после паузы:

«🦫 Dawno się nie widzieliśmy! Бобек рад снова тебя видеть. Загляни на короткий урок — путешествие продолжается! ❤️»

Кнопка: «🚀 Вернуться в игру».

Подбирай иллюстрацию по типу уведомления. Используй реальные данные о последней активности, прогрессе и серии.

Уважай согласие на уведомления, выбранное время и часовой пояс. Не отправляй несколько ежедневных напоминаний в сутки.

Исправь обработку неудачной отправки, чтобы ошибка Telegram не оставляла ложную запись об успешно доставленном напоминании. Одновременно не допускай повторной рассылки при конкурентных запусках Cron.

Этап 6. BotFather

Обнови apps/server/scripts/setup-bot.mjs:

* Зарегистрируй все 9 команд.
* Сохрани кнопку запуска Mini App.
* Не перезаписывай вручную настроенное мной описание.
* Не изменяй Description Picture.
* Не сбрасывай токен и webhook.
* Сохрани обработку платежей Telegram Stars и возвратов.

Этап 7. Проверки

После изменений:

1. Проверь /start и остальные восемь команд.
2. Проверь фотографии и публичные HTTPS URL.
3. Проверь реальные переходы по каждой кнопке.
4. Проверь первый запуск, повторный запуск и реферальные ссылки.
5. Проверь согласие на уведомления и /stop.
6. Проверь сообщения на iOS и Android.
7. Запусти typecheck, тесты и сборку.
8. Исправь найденные ошибки, не ограничиваясь отчётом.

В финале предоставь список изменённых файлов, результаты тестов, перечень реализованных команд и инструкции по развёртыванию.

Не утверждай, что бот уже обновлён в Telegram, пока изменения не развернуты на сервере.

Работай последовательно, самостоятельно, без агентов. Не расходуй ресурсы на дополнительные игровые системы, пока Telegram-бот не завершён.
