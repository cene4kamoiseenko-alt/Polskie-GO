# POLSKI GO — game map art + interactive demo

## Что находится в архиве

- `assets/map_full.png` — главная рабочая иллюстрация карты Польши **941 × 1068 px**. Картинка взята из ранее утверждённого пользователем концепта, обрезаны шапка и нижнее меню. Использовать как визуальный слой карты.
- `assets/map_full_2x_upscaled.png` — 1882 × 2136 px, увеличено алгоритмом Lanczos (это **НЕ** восстановление настоящих новых деталей).
- `assets/original_design_reference.png` — полный утверждённый экран с UI, **только референс**, не помещать поверх существующего UI приложения.
- `assets/tiles/01_north.png`, `02_middle.png`, `03_south.png` — части карты с пересечением 20 px. Для произвольной сборки лучше брать цельную PNG: так не будет швов.
- `data/cities.json` — **20 городов** с якорями для клика в пикселях и процентах относительно `map_full.png`; не путать эти визуальные координаты с географическими широтой/долготой.
- `demo/index.html` — автономный интерактивный прототип: прокрутка/масштаб, кликабельные города, выбор города, пример UI нижней карточки. Для просмотра открыть `demo/index.html` браузером или через статический сервер; это **не готовая интеграция с бэкендом**.
- `instructions/PROMPT_FOR_CLAUDE_RU.md` — подробное задание для Claude Code, который должен встроить материалы в реальный проект.

## Важно: пределы PNG

В исходной утверждённой иллюстрации уже **нарисованы** названия, звёзды и часть элементов карты. Их нельзя независимо редактировать, включать/выключать или переводить, не переделав фон. Интерактивные HTML-кнопки в демо стоят поверх этих рисунков. В финальной реализации нельзя использовать пиксельную картинку как источник истинного прогресса: прогресс, доступность уроков, экономика и достижения берутся только из реального приложения.

**Для быстрой первой реализации**: поместить `map_full.png` в скроллируемое/масштабируемое поле и отрисовать невидимые `button` поверх городов, всё связать с реальными событиями приложения.

**Для окончательной реализации**: заказать или сгенерировать СТРОГО ТОТ ЖЕ изометрический фон БЕЗ текста, звёзд, эмблем и персонажа, чтобы поверх него выводить управляемые компоненты. Пока такой полностью чистый послойный оригинал не создан, текущая картинка — качественный визуальный MVP, но не редактируемый Photoshop/векторный исходник.

## Дополнительные требования к интеграции

1. Сначала аудит текущих маршрутов/моделей городов и уроков, не удалять никакие задания и доступные города.
2. Не строить 20 новых маршрутов, если они уже есть: использовать `id`/данные проекта. Сопоставить slugs между JSON и кодом.
3. На телефоне (360, 390, 430 px) сделать безопасную область, pan + pinch zoom, зум кнопками и фокус камеры на текущем городе; не делать исходную маленькую карту на весь экран, если подписи станут нечитаемыми.
4. Использовать существующую локализацию (RU/UK/PL/EN), не переносить английские подписи нижней карточки исходного референса в продукт как константы.
5. Состояния completed/available/locked считать из существующей серверной логики, без обхода уроков. `demo_status` только для демонстрации.
6. Не делать UI карты скриншотом: верхняя панель и нижнее меню должны оставаться настоящими HTML/CSS/React компонентами.
7. Bobek и настоящие анимации по возможности отображать отдельными слоями, а не дублировать персонажа, который уже впечён в старый концепт.
8. Вернуть реальные скриншоты 360/390/430 px и отчёт с тестами.

## Картографическая достоверность

Города на рисованном концепте расположены приблизительно, художественно, и не гарантируют географической точности. Изображение пригодно как **игровая карта уровней**, не как навигационная карта. Если важна точность, нужно отдельно сделать привязку к настоящему контуру Польши и координатам городов.
