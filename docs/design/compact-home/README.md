# Эскизы компактной главной

`practice-icons-master.png` — отклонённый пользователем образец: слишком глянцевый, игрушечный материал. В интерфейсе не используется. Новые иконки должны соответствовать живописным `icons/house.webp`, `icons/dictionary.webp`, `icons/explore.webp`: тёплые фактурные материалы, детальная рисованная 2.5D-графика, без кремовых плиток и пластикового вида.

Пользователь одобрил новый образец повторения — кожаная книга с латунной стрелкой. По этому стилю сгенерированы шесть отдельных мастеров `*-approved.png`: повторение, исправление ошибок, короткая практика, быстрый раунд, настройки, сообщество. Оригиналы генерации дополнительно сохранены в `/workspace/generated_images`.

Рабочие файлы — `apps/web/src/assets/icons/{review,mistakes,timer,speed,settings,friends}.webp`: 256×256 с альфой, без текстовых подписей. Подхватываются существующим `iconAsset()`; прежний SVG для этих шести GameIcon больше не используется. `Art clock` использует готовый секундомер.

Повторная подготовка размеров и кодирования: `node scripts/build-compact-icons.mjs`. Мастера не загружаются в приложение. Отклонённый набор не подключён к runtime.

Отклонённый лист `practice-icons-master.png` и промежуточный `review-candidate.png` сохранены локально и исключены из публикации. В репозиторий входят шесть одобренных мастеров `*-approved.png` и рабочие WebP.
