# Мастера экрана загрузки (пакет владельца 2026-11-01)

Источник: два архива владельца — `POLSKI_GO_loading_screen_4_PNG.zip` (четыре цельных концепта 941×1672) и `POLSKI_GO_LOADING_LAYERED_ANIMATED.zip`
(те же концепты, автоматически разделённые на слои + прототип HTML/CSS/JS). Здесь лежат только мастера, из которых собираются ассеты приложения
(`node scripts/build-splash-art.mjs`).

| Файл | Что это |
|---|---|
| `<тема>_background_clean.jpg` | «чистый» фон 941×1672 из архива: на месте логотипа, Бобека и карточки остались призраки (README архива: «фон восстановлен ориентировочно») |
| `<тема>_bobek.webp`, `<тема>_logo.webp` | вырезанные автоматически слои с альфой (из PNG архива без потерь) |
| `originals/<NN>_<тема>_original.webp` | цельные концепты (WebP 92): настоящая сцена вокруг Бобека берётся отсюда, они же — эталон вида |

Темы: `royal` (04, синее небо, рабочая), `sunset` (01, закат), `adventure` (03, путешествие) — вторые две только для разработки (`?splash=<тема>`).
Тема «soft» (02, «Мягкий») по решению владельца **не берётся**: Бобек там заметно размытее остальных (резкость слоя, дисперсия лапласиана: soft 476
против 714 у royal, 788 sunset, 935 adventure); её мастера в репозиторий не вошли и остаются у владельца в архиве.

Подробности — `docs/LOADING_SCREEN.md`.
