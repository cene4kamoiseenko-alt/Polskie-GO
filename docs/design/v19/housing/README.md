## Сцены с Бобром — `scenes/` (в приложении)

`<город>_<сцена>.webp`, 1536×1024 (3 : 2), WebP q90 из присланных PNG; Бобёр нарисован в картинке. Сцены: `read` (читает) · `sleep` (спит) · `work` (работает) · `tea` (пьёт чай).
Сборка: `node scripts/build-housing-art.mjs` → `apps/web/src/assets/housing/housing-<город>-<сцена>{,@640}.webp`. Нет мастера — нет и сцены (экран показывает только имеющиеся).
