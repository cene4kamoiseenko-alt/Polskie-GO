# Мастера готовых образов Бобека (пакет владельца 2026-11-01)

Источник: архив `BOBEK_31_INDIVIDUAL_AND_GALLERIES.zip` (SHA-256 начинается с `5b7b5296461d17f5`), 31 изображение и контактные листы.
Здесь лежат только мастера, из которых собираются образы приложения (`node scripts/build-bobek-variants.mjs`). Файлы 17–23 (костюмы) не
копировались: они совпадают пиксель в пиксель с `apps/web/src/assets/costumes/*.webp` (проверено, разница 0).

| № | Файл | Серия | Что это |
|---|---|---|---|
| 01–08 | `01_hoodie-red.webp` … `08_…` | wave, чистые | 512×512, прозрачный фон, машет рукой с картой |
| 09–16 | `09_…` … `16_…` | wave, с дефектами | «экспериментальные сочетания»: полупрозрачные разводы вокруг фигуры (до 3800 px), в 09 ещё и призрак на щеке |
| 24–31 | `24_…` … `31_…` | open, чистые | 1254×1254 на ровном бежевом фоне (без альфа-канала), руки разведены, 8 сочетаний |

Формат имени: `NN_hoodie-red[_cap-red][_glasses-round][_scarf-pl][_backpack-green].webp`; `backpack-green` — это `backpack-travel` каталога.

Формат хранения: серия 01–16 — WebP без потерь (бит в бит с PNG владельца); серия 24–31 — WebP качества 97 (в PNG по 1,6–1,8 МБ, в репозиторий
не нужны). Оригиналы остаются у владельца в архиве.

Как они превращаются в образы приложения и что не лечится автоматически — `docs/BOBEK_VARIANTS.md`.
