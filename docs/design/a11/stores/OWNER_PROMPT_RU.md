# POLSKI GO — SONNET, ПОДКЛЮЧЕНИЕ ПЯТИ ЛОКАЦИЙ

Продолжай существующий репозиторий, не повторяй предыдущие этапы. Этот архив содержит пять отдельных сцен с магазинами/сервисами: Żabka, Biedronka, Rossmann, ORLEN, InPost.

**Сначала** прочитай `README_RU.md` и `asset-manifest.json`. Критическое ограничение: это аккуратно выделенные сцены с ограниченным родным разрешением из сгенерированной доски, а не полнокадровые нативные PNG высокого разрешения. Не называй их final asset masters.

1. Сверь существующие ID категорий/заданий и файлы картинок, не изменяй существующий код и уроки без необходимости.
2. Подключи подходящие сцены по назначению: żabka — быстрые покупки и разговор с кассиром; biedronka — продукты/цены; rossmann — косметика и бытовые товары; inpost — посылка/код получения; orlen — дорога/заправка и кафе.
3. Используй `02_lesson_backgrounds_1440x720_webp` для карточек уроков, `05_cards_640x320_webp` для маленьких превью. Для Telegram применяй `03_telegram_1280x720_jpg` (если сообщение действительно использует подходящую сцену).
4. Не помещай поверх сцен второго Бобека: текущий вариант уже содержит статичного персонажа. Для настоящего гардероба пометь эти сцены временными, позже замени на версии окружения без персонажа. Динамический Бобек будет независимым character renderer от Opus.
5. Перепроверь вывески, цены и брендирование. AI может ошибаться в текста/логотипах. Не используй нарисованные надписи как достоверные данные или задания. Изображения не подтверждают официальное партнёрство.
6. Не добавляй blurred padding, не растягивай изображение с изменением пропорций. Выбирай object-fit: cover и вручную проверяй фокусировку для 360 и 390 px.
7. Для каждого файла введи стабильный scene_id, проверь существование ресурса и корректную загрузку, добавь только необходимые тесты манифеста и скриншоты.
8. Не меняй цены, XP, прогресс пользователей, не пересоздавай старые уроки и не пушь без отдельного разрешения.

Осталось отдельно создать качественные настоящие 16:9 / 2:1 фоновые мастера без статичного Бобека, так как предоставленный генератор упорно выдаёт коллажи. Зафиксируй эти 5 задач в общем PROJECT_PROGRESS.md.
