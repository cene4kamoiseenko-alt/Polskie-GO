# Доски владельца, 2026-10-27 (референсы редизайна Mini App)

Это **референсы стиля и композиции**, а не ассеты приложения: текст на русском вшит в картинку, цифры — макетные, разрешение мало для нарезки.

| Файл | Что брать | Чего не брать |
|---|---|---|
| `bobek-character-sheet.webp` | эталон Бобека: палитра, пропорции (~2,5 головы), ракурсы, 7 эмоций/поз (приветствие, ходьба, сидит, радость, задумчивый, слушает, волнуется) — список поз для анимаций | нарезать спрайты отсюда нельзя: фон вшит, позы ~150 px. Нужны отдельные прозрачные слои на холсте 1024 (ADR-005) |
| `wardrobe-layers.webp` | слоты одежды (голова, очки, верх, низ, обувь, рюкзак, аксессуар), статусы «Надето / Куплено / Получено / Купить / Примерить», карточка предмета | цены — макетные |
| `home-reward-lesson-done.webp` | главная («Текущий город», уровень, серия, Złotki, «Сегодня»), экран «Все задания выполнены», «Новая награда», «Урок завершён» (XP, Złotki, точность) | — |
| `map-city-cards.webp` | карта с иконками городов и замками, сетка «Выбери город», карточка города, темы города с сундуками | счётчики уроков (Warszawa 12/40, Wrocław 8/38, Gdańsk 0/42…) не совпадают с реальными (26 / 5 / 0) |
| `loading-offline.webp` | загрузка, «Секундочку…», «Нет соединения» с «Попробовать снова» и «Продолжить офлайн» | процент загрузки должен быть реальным, не нарисованным |
| `notification-cards.webp` | стиль карточек уведомлений (продолжить урок, новый город, миссия, произношение, серия, награда, челлендж) | надписи на картинках — для бота нужны версии без текста |
| `overview-features.webp`, `promo-columns.webp` | промо и скриншоты для магазинов приложений | обещания «Говори как носитель» и оценки «Произношение 95 / Интонация 88 / Уверенность 90»: приложение распознаёт слова, а не оценивает фонетику — такие шкалы не делать без реальной оценки произношения |
