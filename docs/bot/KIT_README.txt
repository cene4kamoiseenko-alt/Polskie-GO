POLSKI GO — комплект фотографий для Telegram Bot API.
Распаковать в корень репозитория. Картинки появятся в apps/web/public/bot/commands.
Использовать в sendPhoto как HTTPS-ссылки: <WEB_APP_ORIGIN>/bot/commands/<command>.jpg.
Все изображения: JPG 1280x720, стандартное соотношение 16:9.
Для некоторых нейтральных команд пока повторно используется готовое фото,
чтобы не задерживать запуск. Позже можно заменить на тематическое без изменения API.
Перед развёртыванием протестировать публичную доступность URL и 200/image/jpeg.
Не менять уже настроенную BotFather Description Picture: это отдельная картинка.
