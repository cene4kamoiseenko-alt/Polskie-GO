# Качество заданий: чтобы ответ нельзя было угадать без знания языка

Правила для тех, кто пишет уроки, и измеримая проверка. Тесты структуры (`content-rules.ts`) доказывают, что задание собрано правильно; они не доказывают, что оно **хорошее**. Хорошее задание проверяет то, чему учит урок, а не умение угадывать.

## Что показал замер (2026-11-01, `scripts/exercise-quality.ts`)

- **Во всех 15 городах 100% шагов диалогов — с двумя вариантами.** Это монетка: половину диалогов можно пройти не глядя. Неверный вариант почти всегда — явная ошибка вида «после *proszę* стоит спряжённая форма», которую видно по виду слова.
- «Верный ответ самый длинный» — в уроках не встречается (0 замечаний).
- «Послушай» с далёкими вариантами: Warszawa 5 из 10, Wrocław 2 из 10, остальные города — 0.
- «Вставь слово» с вариантами разных слов вместо форм одного слова: Katowice 3, Bydgoszcz 2, Kraków 1, Gorzów 1.

**Что сделано:** Olsztyn переработан (три варианта в каждом шаге диалога, правдоподобные ошибки, более тонкие «лишнее слово» и чтение), правило закреплено тестом `richDialogues` для новых городов. **Что остаётся:** ~250 шагов диалогов в 14 старых городах и 7 «Послушай» Warszawa и Wrocław. Список — `node --import tsx scripts/exercise-quality.ts <город>`.

## Правила авторам

1. **Диалог: три варианта в каждом шаге.** Два неверных варианта — разные по природе: (а) типичная ошибка ученика (форма, предлог, род), (б) грамматически верная, но неуместная фраза (другой смысл, неподходящий тон, перепутанная причина и следствие, не сходится с фактами сцены). Если оба неверных варианта «сломаны», ответ находят по внешнему виду.
2. **Объяснение у каждого неверного варианта** — что именно не так и как правильно, без «нельзя».
3. **Вставь слово:** варианты — формы одного слова или близкие конструкции (*nad / na / w*, *który / która / które*), а не слова разных частей речи. Если подойдут два варианта по смыслу, задание неправильное.
4. **Послушай:** неверные варианты отличаются от звучащей фразы одним значимым элементом — числом (*dwanaście / dwadzieścia*), окончанием, предлогом, отрицанием, временем. Сходство с верной фразой 0,6–0,95; ниже 0,5 различать на слух нечего.
5. **Чтение:** вопрос на деталь или вывод, а не на слово, которое стоит в первом предложении. В тексте есть и верный ответ, и «соблазнительный» (число, имя, место, которое легко перепутать).
6. **Перевод слова:** неверные варианты из того же круга значений (родственные слова, ложные друзья), а не из другой области.
7. **Лишнее слово:** признак лишнего не должен быть виден по написанию или части речи. Хорошо: «три с *prosimy o* + существительное, одно с инфинитивом». Плохо: «три про поезда, одно про кофе».
8. **Длина и место верного варианта** не должны его выдавать (позиция перемешивается сервером; длину следит скрипт).
9. **Польский пишет и проверяет человек со слухом на язык.** Тест не отличает «звучит естественно» от «грамматически допустимо»: каждый новый урок нужно показать носителю (`docs/CONTENT_AUDIT_RU.md`, раздел города).

## Как проверить

```
node --import tsx scripts/exercise-quality.ts                 # сводка по всем городам
node --import tsx scripts/exercise-quality.ts olsztyn         # + список заданий города
node --import tsx scripts/exercise-quality.ts --strict olsztyn bialystok   # код 1, если есть замечания
```

Для новых городов `richDialogues: true` в `citySuite` (`test/new-cities.test.ts`) требует: не меньше трёх вариантов в шаге, объяснение у неверных, верный вариант самый длинный не чаще чем в 60% шагов.
