# POLSKI GO — ручная проверка в Telegram (iOS и Android)

Автоматические проверки идут в Chromium (`npm run e2e`). Telegram WebView на iPhone и Android они не заменяют: жесты, системная кнопка «Назад», safe-area и поведение без сети там другие. Этот чек-лист проходит человек на реальном телефоне.

Пока ни один пункт на устройстве не проверен. Отметка `[x]` ставится только после проверки на реальном телефоне, с моделью, версией iOS/Android и версией Telegram в таблице внизу.

## Подготовка

- Открыть бота и Mini App из ветки `claude/polski-go-telegram-app-r8helf` (сборка Cloudflare).
- Проверить в двух темах Telegram: светлой и тёмной.
- Отдельно проверить с включённым «Уменьшить движение» (iOS: Настройки → Универсальный доступ → Движение) и с переключателем «Меньше анимаций» в профиле приложения.

## A. «Сегодня» на главной

Ожидание: скелетон виден только пока идёт загрузка, затем всегда одно из состояний. Атрибут `data-today` в коде: `loading`, `active`, `done`, `empty`, `error`, `offline`.

- [ ] Обычный запуск: скелетон исчезает не позже чем через несколько секунд, видны карточки заданий (`active`).
- [ ] Все задания дня выполнены: строка «новые задания через N ч» (`done`), без скелетона.
- [ ] Авиарежим после загрузки, затем вернуться на главную: сообщение «нет связи» (`offline`), а не вечный скелетон.
- [ ] Авиарежим выключен: блок сам возвращается к заданиям или работает кнопка «Повторить».
- [ ] Состояния `empty` и `error` вручную не воспроизводятся (нужен ответ сервера). Они проверены только в e2e.

## B. Шторка города на карте

- [ ] Открыть город на карте: шторка поднимается, ручка вверху видна.
- [ ] Прокрутить список уроков пальцем до самого последнего урока: шторка не закрывается и не дёргается.
- [ ] Кнопка действия внизу шторки видна без прокрутки и не перекрыта домашней полосой iPhone.
- [ ] Потянуть за ручку вниз: шторка закрывается.
- [ ] Крестик закрывает шторку.
- [ ] Системная кнопка «Назад» Telegram при открытой шторке закрывает шторку, а не уходит с карты.
- [ ] После закрытия шторки «Назад» снова ведёт себя как на карте (скрыта или уводит на предыдущий экран), без двойного срабатывания.
- [ ] Повернуть телефон и вернуть обратно: шторка не выходит за экран.

## C. Бобек на карте

- [ ] На текущем городе стоит живописный Бобек на коралловой платформе, не пустая платформа.
- [ ] После урока, открывшего следующий город: Бобек идёт по маршруту и останавливается на новом городе, не телепортируется через закрытые этапы.
- [ ] С «Уменьшить движение» или «Меньше анимаций»: Бобек не покачивается, переход между городами мгновенный.
