# Экран загрузки по слоям владельца (2026-11-01)

Заменил заставку «панорама + бобёр-растр» на слои из архивов владельца: фон «Замковая площадь, Варшава», логотип и Бобек — отдельные картинки на сцене
941×1672, поверх — стеклянная карточка с **реальным** прогрессом запуска. Тот же экран — при ошибке сети и на первом шаге знакомства.

## Что видит пользователь

- **До JS** (`index.html`): тот же фон и логотип на тех же местах, логотип появляется один раз (CSS, 0,85 с). Дальше его без прыжка подхватывает React
  (проверено: положение логотипа и фона совпадает с точностью до пикселя на 320 / 390 / 430).
- **Загрузка** (`components/Splash.tsx`): Бобек выезжает снизу и покачивается, карточка: иконка фразы, фраза (15 вариантов, меняются каждые 1,9 с), процент,
  бирюзовая полоса со бликом, строка «Шаг N из 3 · что сейчас делается» и метка «Polski GO».
- **Ошибка / нет сети / медленно**: та же сцена; карточка ошибки с «Попробовать ещё», значок wi-fi у головы Бобека при отсутствии сети; при затянувшемся этапе
  (> 8 с) подпись «Связь медленная — ещё пробуем» и «Попробовать ещё» (переносятся целиком, не обрезаются).
- **Знакомство** (первый шаг): сцена поднята на 5,5 % высоты, под логотипом слоган и шаги, внизу реплика Бобека и две кнопки.
- **«Меньше анимации»** (настройка профиля) и системное prefers-reduced-motion: не движется ничего (ни покачивание, ни блик, ни появление).

## Прогресс настоящий

Проценты берутся из `lib/boot.ts` (метки этапов ставятся там, где они действительно кончаются: вход → профиль → первый экран); таймеров и фальшивых
запросов нет. Вес этапов (12 / 45 / 82 / 100 %) не менялся. Вариант архива (`setProgress` с весами 35/35/30) не использован: у приложения свои реальные этапы.

## Слои и сцена

- Положение слоёв — в процентах кадра 941×1672 (`lib/splashArt.ts`, числа из `loading.js` архива). Сцена накрывает экран как `cover` (CSS: `--u` — пикселей
  экрана на пиксель кадра), слои лежат внутри неё, поэтому не расходятся на любых экранах. На высоких экранах обрезаются края, на низких — верх и низ.
- Ассеты: `apps/web/src/assets/splash/royal/{bg,bg@640,bobek,logo}.webp` (фон 941 px, `srcset` отдаёт 640 px только узким экранам с DPR 1).
  Мастера — `docs/design/v19/loading/` (README там).
- Темы: рабочая одна — `royal`. `sunset` и `adventure` — `src/dev/splash-themes/`, включаются `?splash=sunset` только при разработке; в production-сборку не входят
  (плагин `pg-dev-splash-themes-out-of-build` в `vite.config.ts`: иначе Rollup тащил их в `dist`). Тема soft («Мягкий») не берётся: Бобек размыт.

## Чистка фонов (`scripts/build-splash-art.mjs`)

«Чистые фоны» архива не чистые: на месте логотипа, Бобека и карточки призраки (владелец об этом знает, README архива). Пока слои стоят, их не видно; при
покачивании Бобека и появлении логотипа они вылезали. Конвейер перерисовывает три зоны (оригиналы не меняются):
1. логотип: небо вокруг и под ним (+14 px) — гладкая интерполяция по окружению;
2. Бобек: вокруг силуэта настоящая сцена берётся из оригинального композита (у «чистого» фона там шов от заливки); полоса «9 px снаружи … 14 px внутрь» силуэта —
   продолжение цветов снаружи (покачивание не выходит за ~10 px), без шва и ореола;
3. карточка: полоса y 1226…1582 — интерполяция плюс настоящая брусчатка из чистой нижней полосы кадра (зеркально). Под стеклянной карточкой это размытая брусчатка.

**Что не вылечено** (нужны чистые мастера): у тем sunset и adventure на логотипе заметны слабые прямоугольные следы вырезки; у sunset в зоне брусчатки зеркально
повторились красные цветы; фон 941 px в ширину, на телефонах с DPR 3 (390 css px → 1170 px и больше) он растянут примерно в 1,2–1,5 раза (картинка чуть мягче); контуры вырезанного Бобека и логотипа
автоматические, не чистовые. Это промежуточный результат, а не исходник PSD/Figma.

## Проверки

- `scripts/splash-screens.ts` (Chromium, 320 / 360 / 390 / 430; снимки — `test-results/splash-screens/`, не в git): сцена накрывает экран, слои и карточка в кадре,
  карточка не закрывает Бобека, нет горизонтальной прокрутки, этап и процент настоящие, «Меньше анимации» выключает все движения, все 15 фраз × 3 языка в две строки,
  ошибка / нет сети / медленно, совпадение index.html и React, знакомство, dev-темы.
- `npm run e2e`, `npm run a11y`, `npm run screens` — классы `.splash`, `.splash-card`, `data-boot`, `data-boot-error` сохранены.
- **На реальных iPhone и Android не проверялось.** Не проверены: полноэкранный режим Telegram (верх логотипа и шапка Telegram), VoiceOver / TalkBack, слабые устройства.

## Что нужно от владельца

- чистые мастера: фон без логотипа, Бобека и карточки (шире 1400 px), Бобек и логотип с чистой альфой — после этого чистка в конвейере не нужна;
- решение, нужны ли dev-темы sunset / adventure (и чистые логотипы к ним) или их убрать;
- оставлять ли ротацию 15 фраз с иконками (концепт показывает одну фразу «Отправляемся в Краков…»).
