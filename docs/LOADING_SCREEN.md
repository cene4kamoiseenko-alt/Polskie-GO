# Экран загрузки по слоям владельца (2026-11-01)

Заставка собрана из слоёв владельца: фон «Замковая площадь, Варшава», логотип и Бобек — отдельные картинки на сцене 941×1672, поверх — стеклянная карточка с **реальным**
прогрессом запуска. Тот же экран — при ошибке сети и на первом шаге знакомства.

История версий (все в этом дне):
1. слои из архивов владельца («чистые» фоны с призраками логотипа и Бобека, вырезки с обрезанными лапами) + программная чистка;
2. логотип с украшением — одна группа под шапкой Telegram, минимальное время показа 1,7 с;
3. **чистые мастера** владельца (фон 1536×1024 без логотипа, Бобека и карточки; Бобек и логотип с чистой альфой): чистка призраков, достройка лап и вся связанная с ними
   геометрия удалены; фон собирается из широкого мастера; минимум показа 2,4 с (владелец: «ещё немного дольше»).

## Что видит пользователь

- **До JS** (`index.html`): тот же фон и логотип на тех же местах, логотип появляется один раз (CSS, 0,85 с). Дальше его без прыжка подхватывает React
  (проверено: положение логотипа, украшения и фона совпадает с точностью до пикселя на 320 / 390 / 430).
- **Логотип**: логотип и украшение над ним (замок, лавр, дуги) — одна группа шириной ≈ 74 % экрана по центру, **ниже кнопок Telegram** (safe area + 12 px, не выше 44 px).
  Логотип — мастер владельца с синей обводкой (отдельной тени в CSS нет).
- **Время показа** (по просьбе владельца: сначала заставку не успевали увидеть, затем «ещё немного дольше»): не меньше `SPLASH_MIN_MS = 2400` мс от начала загрузки страницы
  (`lib/boot.ts`; было 1700). Если всё загрузилось раньше, полоса за остаток времени доходит до 100 % (фраза «Бобёр уже ждёт тебя!»), потом открывается приложение.
  Медленная загрузка не удлиняется, ошибка заставку не держит. Пока заставка держится, первый экран уже загружается под ней (скрыт и недоступен: `visibility: hidden`, `inert`),
  поэтому после паузы он готов, а не начинает грузить данные только теперь. Менять — одной константой (тест берёт значение из исходника).
- **Загрузка** (`components/Splash.tsx`): Бобек выезжает снизу и покачивается, карточка: иконка фразы, фраза (15 вариантов, меняются каждые 1,9 с), процент,
  бирюзовая полоса со бликом, строка «Шаг N из 3 · что сейчас делается» и метка «Polski GO».
- **Ошибка / нет сети / медленно**: та же сцена; карточка ошибки с «Попробовать ещё», значок wi-fi у головы Бобека при отсутствии сети; при затянувшемся этапе
  (> 8 с) подпись «Связь медленная — ещё пробуем» и «Попробовать ещё» (переносятся целиком, не обрезаются).
- **Знакомство** (первый шаг): сцена поднята на 5,5 % высоты, под логотипом слоган и шаги, внизу реплика Бобека и две кнопки. Слоган и шаги частично закрывают небо и голову статуи
  (стеклянные плашки) — так задумано, лицо Бобека они не закрывают (проверяется).
- **«Меньше анимации»** (настройка профиля) и системное prefers-reduced-motion: не движется ничего (ни покачивание, ни блик, ни появление).

## Прогресс настоящий

Проценты берутся из `lib/boot.ts` (метки этапов ставятся там, где они действительно кончаются: вход → профиль → первый экран); таймеров и фальшивых
запросов нет (единственная пауза — минимум показа, и в ней полоса честно идёт к 100 % за оставшееся время). Вес этапов (12 / 45 / 82 / 100 %) не менялся.

## Слои и сцена

- Положение слоёв — в процентах кадра 941×1672 (`lib/splashArt.ts`; числа печатает конвейер). Сцена накрывает экран как `cover` (CSS: `--u` — пикселей экрана на пиксель кадра),
  слои лежат внутри неё, поэтому не расходятся на любых экранах. На высоких экранах обрезаются края, на низких — верх и низ.
- Ассеты: `apps/web/src/assets/splash/royal/{bg,bg@640,bobek,logo,orn}.webp`. Фон 941×1672 (кадр), `srcset` отдаёт 640 px только узким экранам с DPR 1; Бобек и логотип — по 1,25 пикселя на пиксель кадра. Первая попытка была крупнее (фон 1129×2006, слои по 1,4):
  картинки заставки выросли с 560 до 636 КБ и LCP холодного старта вышел за бюджет (2524 мс > 2500), поэтому размеры уменьшены.
- Мастера — `docs/design/v19/loading/clean/` (фон, Бобек, логотип владельца; WebP, Бобек и логотип без потерь), старые мастера архива и цельные концепты — рядом (README там).
- Тема одна — «Замковая площадь». `sunset`, `adventure` (были dev-темами через `?splash=`) убраны, тема soft («Мягкий») не берётся (Бобек размыт); их мастера лежат в `docs/design/v19/loading`.

## Конвейер (`scripts/build-splash-art.mjs`, `scripts/lib/sprite.mjs`)

С чистыми мастерами чистка призраков (push-pull вокруг логотипа, заливка вокруг Бобека, достройка лап, перерисовка карточки) не нужна и удалена. Что делает конвейер:

1. **Фон.** Кадр приложения портретный, мастер альбомный 3:2. Сцена масштабируется 0,84 (в таких же пропорциях стояли дома и колонна в концепте), ставится так, чтобы колонна Сигизмунда стояла
   слева за Бобеком, и достраивается: **небо сверху** (под логотипом: цвет верхних строк мастера, к зениту чуть гуще, облака — отражение верха мастера, колонну не отражаем: иначе перевёрнутая статуя) и
   **брусчатка снизу** (под карточкой: зеркальное продолжение чистой полосы площади, дальше темнее и мягче). Под ногами Бобека — мягкая контактная тень (в мастере он студийный, без тени).
2. **Бобек.** В мастере «непрозрачное» — 253 из 255 (слой на 1 % прозрачный, а снаружи по контуру кромка подкрашена красным): альфа ≥ 240 → 255, полупрозрачные точки внутри силуэта закрываются,
   цвет кромки берётся у ближайшего плотного пикселя. Слой обрезается по содержимому и масштабируется до видимой высоты 620 px кадра; ноги — на линии y = 1216, точка вращения покачивания — низ слоя.
3. **Логотип.** Слой обрезан по содержимому, видимая ширина 694 px кадра; верх букв на y = 172, центр по горизонтали 481.
4. **Украшение над логотипом** (замок, лавр, дуги) — в мастере логотипа его нет, поэтому оно остаётся отдельным слоем `orn.webp`, вынутым из цельного концепта по белизне (min(R,G,B) на синем небе).
   Приложение собирает логотип и украшение в одну группу.

Конвейер печатает рамки слоёв и числа мгновенной заставки `index.html` (`.pre-lockup`, `.pre-orn`, `.pre-logo`): после пересборки их нужно переписать в `lib/splashArt.ts` и `index.html`; расхождение ловит
сравнение пикселей в `scripts/splash-screens.ts`.

**Покачивание Бобека** — вверх на 5 px, наклон ≤ 0,5°, масштаб ≤ 1,008 от линии ног: фон чистый, но больше уже не «дышит», а подпрыгивает.

**Что не вылечено:** контуры вырезок и украшение над логотипом — автоматические; украшение взято из концепта (941 px), на DPR 3 чуть мягче остального. Фон — достроенный: небо сверху и брусчатка снизу
нарисованы программно, а не владельцем; в сцене мастера они выглядят естественно, но это не его кадр. Если нужен чистовой вариант, нужен портретный мастер (≥ 1400 px шириной).

## Скорость (perf, холодный старт, 390×844, 4× CPU, 9 Мбит/с)

Чистые слои (замер 2026-11-01): FCP 752 мс, **LCP 1792** (первая версия слоёв — 2132; крупные чистые слои — 2524, за бюджетом), готовность 2630 мс, картинки 594 КБ (бюджет 800), JS 760 КБ (бюджет был 760 — запаса нет),
CSS 108 КБ; повторное открытие 2541 мс (бюджет 3000; минимум показа 2,4 с). Вечером того же дня картинки «Квестов» и обложки сезонов добавили ≈ 1 КБ (761): бюджет JS **760 → 770 КБ** — осознанно, с объяснением в `scripts/perf.ts` (замер: FCP 716, LCP 1712, готовность 2530, JS 761, картинки 676 КБ, повторное открытие 2514 мс). Урок первой версии: мгновенная заставка с анимацией появления логотипа **от `opacity: 0`** портила FCP (712 → 1172 мс): браузер
не засчитывает элемент с нулевой прозрачностью как первую отрисовку, а анимация идёт на композиторе и страницу не перерисовывает. Теперь анимация стартует с `opacity: 0.01`, логотип грузится с
`fetchpriority="high"`, фон — `low`. Шум одного прогона — ±250 мс.

Минимальное время показа сдвинуло бюджет **повторного открытия** в `scripts/perf.ts`: 1500 → 2200 (1,7 с) → 3000 мс (2,4 с). Холодный старт дольше минимума и от него не зависит.

## Проверки

- `scripts/splash-screens.ts` (Chromium, 320 / 360 / 390 / 430; снимки — `test-results/splash-screens/`, не в git): слой Бобека как файл (размер, нет просвечивающих мест внутри силуэта, лапы целые),
  сцена накрывает экран, слои и карточка в кадре, карточка не закрывает Бобека, нет горизонтальной прокрутки, этап и процент настоящие, «Меньше анимации» выключает все движения,
  все 15 фраз × 3 языка в две строки, ошибка / нет сети / медленно, совпадение index.html и React (логотип, украшение, фон), знакомство, логотип под шапкой Telegram (safe area 70 px),
  минимальное время показа (значение — из `lib/boot.ts`).
- `npm run e2e`, `npm run a11y`, `npm run screens` — классы `.splash`, `.splash-card`, `data-boot`, `data-boot-error` сохранены.
- **На реальных iPhone и Android не проверялось.** Не проверены: полноэкранный режим Telegram (верх логотипа и шапка Telegram), VoiceOver / TalkBack, слабые устройства.

## Что нужно от владельца

- по желанию: портретный мастер фона (≥ 1400 px шириной, небо сверху и мостовая снизу нарисованы) — тогда достройка в конвейере не нужна;
- оставлять ли ротацию 15 фраз с иконками (концепт показывает одну фразу «Отправляемся в Краков…»);
- нравится ли 2,4 с (одна константа `SPLASH_MIN_MS`).

## Откат

`git revert` коммита экрана загрузки возвращает предыдущую версию заставки; данные и API не менялись.
