# Недельная лига (вариант А) — план

> Исполнение: в этой сессии (native), задачи по порядку, TDD на сервере.

**Цель:** рейтинг недели для всех активных игроков и награды Złotki за места в конце недели.

**Решения владельца (2026-11-15):** одна общая таблица недели; в неё попадает игрок с ≥ 20 XP за неделю; награды 1 — 300 zł, 2 — 200, 3 — 100, 4–10 — по 25, только при ≥ 100 XP за неделю; итоги в понедельник ночью автоматически; бот пишет победителю; в игре окно с наградой; на экране — счётчик до конца недели, призы за места, «до 3-го места N XP».

**Архитектура:** неделя лиги — по Варшаве для всех (`leagueWeek(now)`), запись XP в `leaderboards` идёт с этим ключом. Итоги недели — `settleLeagueWeek(week, now)` из cron каждые 15 минут: захват недели строкой `league_weeks` (INSERT OR IGNORE), награды через `grantZlotki` с ключом `league:<week>:<userId>`, строки `league_awards`. Сообщения бота — отдельной порцией с бюджетом вызовов. Награда в `/me` — мягким отдельным запросом (старые схемы в тестах миграций не падают).

## Глобальные ограничения
- Пороги и призы — в `packages/shared/src/league.ts` (их показывает и клиент): `LEAGUE_MIN_XP = 20`, `LEAGUE_PRIZE_MIN_XP = 100`, `leaguePrize(rank)`: 1→300, 2→200, 3→100, 4–10→25, иначе 0.
- Порядок мест: XP по убыванию, при равенстве — кто набрал раньше (`updated_at` по возрастанию). Скрытые из рейтинга (`show_in_leaderboard = false`) и заблокированные — не в таблице и без награды; места не сдвигаются из-за игроков ниже 100 XP (их приз просто не выдаётся).
- Без изменения прочей экономики. Тексты — ru/uk/en с одинаковыми ключами.

## Review Focus
1. Итоги запускаются дважды (параллельный cron) — награда одна (тест).
2. Неделя ещё идёт — итоги не подводятся (тест).
3. Игрок с 10 XP не виден другим, но видит себя с подсказкой «набери 20 XP» (тест).
4. Ничья по XP — выше тот, кто набрал раньше (тест).
5. Награда видна в `/me`, после «видел» — нет (тест).
