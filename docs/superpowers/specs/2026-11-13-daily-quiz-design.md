# Вопрос дня в боте — дизайн

Дата: 2026-11-13. Статус: на согласовании у владельца (ответы владельца внесены).

## Зачем

Владелец видит, как польские обучающие каналы в Telegram (t.me/movaschoolpl, t.me/testuj_swoj_polski) держат аудиторию короткими вопросами каждый день. У нас уже есть быстрые вопросы в боте (`/quiz`), но они приходят редко и только тем, кто уже отвечал, без картинки и без перехода к уроку. Цель — **раз в день человеку приходит вопрос по польскому, над которым надо подумать, и через него он возвращается к урокам в приложении.**

Слова владельца: «раз в день человеку приходил quiz», «фото к quiz из того, что у нас есть», «тесты нормального уровня с вариантами ответов такие, чтобы нужно было думать, а не методом исключения понять», «с помощью quiz зазывать пройти урок», «сделаем больше базу вопросов и чтобы вопросы не были из нашего приложения», «картинки разные подберём из нашей базы», «в админ-панели видно, кому как вопрос отправился, ответил человек или нет и правильно или неправильно». Выбран смешанный вариант хранения базы (см. «Подходы»). Ответ владельца о получателях: «рассылка будет всем, будет одна рассылка в день; тем, кто не запустил бота, но что-то написал ему, тоже; но перед тем как запускать рассылку, я должен её видеть в админ-панели — запланированные публикации, все, которые будут».

## Цели

1. Одна рассылка в день: всем, кто писал боту (и игрокам приложения из Telegram), — вопрос с фото из наших сцен, 4 варианта кнопками.
2. Вопросы новые (не повторяют задания уроков приложения) и не угадываются методом исключения.
3. После ответа — пояснение и кнопка в приложение, к уроку.
4. До запуска владелец видит в админке **все запланированные публикации** (на какой день какой вопрос, картинка, варианты, ответ, пояснение) и может их поменять; рассылка не начинается, пока он её не запустит.
5. В админке видно по каждому человеку: отправлен ли вопрос, дошёл ли, ответил ли, что выбрал, верно ли; по каждому вопросу — сколько процентов ответили верно, и вопрос можно выключить без выкладки.

## Не цели (в этой версии)

- Редактор вопросов в админке (вариант 2 из «Подходов») — позже, если владелец захочет писать вопросы сам.
- Встроенные «викторины» Telegram (`sendPoll type=quiz`): фото не в одном сообщении с вопросом, нет кнопки урока.
- Публикация вопроса в канал, аудиовопросы, несколько вопросов дня одному человеку.

## Анти-цели (провал, даже если «работает»)

- Бот превращается в спам: два сообщения в день, рост числа заблокировавших бота.
- Вопросы снова отгадываются исключением или повторяют задания из уроков.
- Картинка подсказывает ответ (например, на фото вывеска с правильным словом).
- Одна и та же картинка у человека два дня подряд.

## Ограничения (из кода и платформы)

- **Пропускная способность.** Cron — раз в 15 минут (`wrangler.jsonc`), за запуск — не больше 35 вызовов Bot API (`SEND_BUDGET` в `apps/server/src/jobs.ts`: бесплатный Worker — 50 подзапросов). Это ≈ 140 сообщений в час на всё: напоминания, вопросы, рассылки. Для рассылки всем этого мало: нужно запускать cron чаще (раз в 1–2 минуты → ≈ 1000–2000 сообщений в час; лимит Telegram на рассылку ≈ 30 сообщений в секунду не мешает) — способ оставлен разработчику; админка показывает, сколько получателей и сколько примерно займёт отправка.
- **Кому бот вообще может написать.** Бот пишет только тем, у кого есть чат с ботом (нажимал Start или писал боту — таблица `bot_contacts`). Игроку приложения, который ни разу не писал боту, Telegram может отказать («bot can't initiate conversation»): такая попытка записывается как «не дошло: нет чата с ботом», и больше этому человеку не шлём, пока он не напишет боту.
- **Telegram.** Подпись к фото — до 1024 символов (вопрос + пояснение должны уместиться после правки сообщения); текст кнопки — коротко (сейчас длиннее 30 символов уходит в текст, кнопки — буквы: `BUTTON_TEXT_MAX` в `engine.ts`). WebP по ссылке как фото ненадёжен → для бота нужны JPG-копии сцен.
- **Языки** интерфейса бота: uk, ru, en. Варианты ответов — польские (или переводы для вопросов «что значит»).
- **Получатели напоминаний сегодня** (`sendReminders`): аккаунт приложения из Telegram (`telegram_id > 0`), не заблокирован, `notifications_enabled`, задан `reminder_hour`, в своём поясе; уже занимавшимся сегодня напоминание не шлём. Те, кто только писал боту и не открывал приложение (`bot_contacts` без `users`), напоминаний не получают. `/stop` у них сейчас ничего не записывает (нет аккаунта) — для вопроса дня отказ нужно хранить по Telegram ID.
- **Ссылки из бота в приложение** — только экраны из белого списка `BOT_SCREENS` (`packages/shared/src/botScreens.ts`): `learn`, `home` и др. Открыть конкретный урок по ссылке сейчас нельзя.
- **Уже есть и переиспользуется:** банк `apps/server/src/bot/quiz/questions.ts` (60 вопросов A1–B1, 9 тем, тексты на 3 языках, пояснения), движок `engine.ts` (отправка с фото, правка сообщения после ответа, ответ принимается один раз условным UPDATE, XP через `grantXp`), таблицы `bot_quiz_rounds` (вопрос, кому, порядок вариантов, выбор, верно ли, когда ответил) и `bot_quiz_players` (выключатель приглашений, счётчик проигнорированных), журнал доставки `notification_log` (SENT / FAILED / BLOCKED, ошибка).
- **Картинки:** 20 сцен приложения в `apps/web/src/assets/scenes/*.webp` (Żabka, Biedronka, Lidl, Rossmann, bar mleczny, pierogarnia, cukiernia, kawiarnia, PKP, tramwaj, lotnisko, Orlen, urząd, InPost, przychodnia, biuro, mieszkanie, Stare Miasto в Варшаве, recepcja w górach, pierniki) и 7 досок бота `apps/web/public/bot/scenes/ru/*.jpg` (с русскими надписями — только для ru). Сейчас ни один вопрос к картинке не привязан (`QUESTION_SCENE_IMAGES` пуст).

## Подходы (как хранить базу вопросов)

1. **База в коде, как сейчас.** Вопросы пишет разработчик, автопроверка качества в тестах; изменить вопрос — выкладка; в админке только статистика. Дёшево, качество под контролем, но владелец не может быстро убрать неудачный вопрос.
2. **База в админке.** Владелец сам добавляет и правит вопросы, выбирает картинку; первые ~200 заливает разработчик. Дорого (редактор вопроса на 3 языках с вариантами и пояснением, проверка «угадывается исключением» при сохранении), риск слабых вопросов, добавленных вручную.
3. **Смешанный — выбран владельцем.** База в коде с автопроверкой качества; в админке по каждому вопросу — сколько раз отправлен и сколько процентов ответили верно, и **выключатель**: вопрос перестаёт приходить без выкладки. Если позже понадобится писать вопросы самому — поверх этого достраивается вариант 2.

## Как это работает (решено)

Решения владельца: большая база, вопросы новые (не из приложения), разные картинки из нашей базы, видимость в админке по каждому человеку, смешанное хранение, рассылка всем раз в день (и тем, кто только писал боту), план публикаций в админке до запуска. Остальное — **предложение разработчика** (помечено «моё решение»), владелец может поправить.

### Сообщение (макет — `test-results/quiz-mock/pytanie-dnia.png`)

1. Приходит одно сообщение: фото сцены, заголовок `🧠 Pytanie dnia · <тема> · <уровень>`, вопрос, 4 кнопки `A · <вариант>` (длинные варианты — в тексте, кнопки — буквы, как сейчас). Время **не ограничено** (моё решение: сообщение часто открывают позже; 20-секундный таймер остаётся только у `/quiz`).
2. После нажатия **то же сообщение меняется** (второго нет): верно / нет, твой ответ, правильный ответ, пояснение (почему верный и чем плохи остальные), «Сегодня верно ответили N % игроков твоего уровня» (показываем, если ответили хотя бы 5 человек — моё решение), `+10 XP` (только с аккаунтом), «вопрос дня N дней подряд».
3. Кнопки после ответа: «📚 Пройти урок · 5 минут» (открывает экран «Учёба», где следующий урок первым — моё решение, пока нет ссылки на конкретный урок; без аккаунта — «🚀 Начать учить польский» на главный экран), «🧠 Ещё вопрос» (обычный `/quiz` с таймером), «🔕 Не присылать вопрос дня» (выключатель `bot_quiz_players.push_enabled`; включить обратно — `/quiz` → кнопка, как сейчас). После выключения человек снова получает обычное ежедневное напоминание (уведомления он не выключал); выключить всё — `/stop` или настройки приложения — моё решение.

### Кому и когда (решение владельца: «всем, одна рассылка в день»)

- **Кому:** все, кто писал боту (`bot_contacts`: `/start`, команда, кнопка, любое сообщение), и игроки приложения из Telegram. **Кроме:** заблокировавших бота, нажавших `/stop`, нажавших «🔕 Не присылать вопрос дня», заблокированных админом, и тех, кому Telegram уже отказал «нет чата с ботом» (пока снова не напишут боту). Отказ хранится по Telegram ID — работает и для тех, у кого нет аккаунта. Игроки, выключившие в приложении ежедневные напоминания, вопрос дня получают (решение владельца «всем»); в настройках приложения появляется отдельный выключатель «Вопрос дня» — моё решение.
- **Когда:** одна рассылка в день, в одно время для всех — время задаётся в админке (по умолчанию 18:00 по Варшаве — моё решение). Отправка идёт частями от этого времени, пока не дойдёт до всех.
- **Одно сообщение в день:** пока рассылка вопроса дня включена, ежедневное напоминание получают только те, кто выключил вопрос дня; остальным вместо напоминания — вопрос (со строкой о серии, см. ниже). Приглашения к `/quiz` в 13:00 / 17:00 тоже отключаются.
- **Уровень:** у игрока приложения — его уровень (как `/quiz` подбирает сейчас); у тех, кто только писал боту, — A1.
- **XP:** +10 за верный ответ — только с аккаунтом; без аккаунта — «XP начисляются после первого входа», кнопка ведёт на первый вход в приложение.
- **Серия дней в приложении** (моё решение по вопросу проверяющего): ответ на вопрос дня серию не продлевает (её продлевают уроки и миссии — `engine.ts`). Поэтому, если у человека серия ≥ 2 дней и сегодня он ещё не занимался, в сообщение с вопросом добавляется строка «🔥 Серия N дней — пройди урок сегодня, чтобы её не потерять», а кнопка урока стоит и до ответа; если не занимался 3+ дня — строка «Давно не виделись — вот вопрос на разминку».
- **Если не отвечает:** после 3 вопросов дня подряд без ответа — пауза: вопрос не приходит, пока человек не ответит на любой вопрос (`/quiz`), не напишет боту или не откроет приложение; игроку приложения в паузе возвращается обычное напоминание — моё решение (не надоедаем и не молчим совсем).

### Какой вопрос

- **По уровню** (моё решение, владелец не возражал): каждый день по одному вопросу на уровень — A1, A2, B1; всем людям одного уровня в этот день — один и тот же вопрос (поэтому можно честно показать «верно ответили N %»). Уровень игрока — тот же, что `/quiz` уже подбирает (`pickQuestion`, уровень ученика A1–B1); без уровня — A1.
- **План публикаций составляется заранее** — на 30 дней вперёд и дополняется каждый день: на каждый день и уровень — вопрос (не выключен, не был вопросом дня этого уровня за последние N дней, картинка не та же, что вчера). Рассылка берёт вопрос из плана; изменить можно любой будущий день (см. «Админка»).
- `/quiz` по запросу использует тот же банк (новые + переписанные старые).

### База вопросов

- **Объём:** около 200 новых (по 60–70 на A1, A2, B1 — два месяца без повторов) + переписанные 60 старых → ~260. Темы те же 9 (покупки, еда и кафе, транспорт, город и urząd, работа, здоровье, быт, грамматика, общение), B1 добирается до того же количества, что A1/A2 (сейчас B1 всего 10).
- **Не из приложения:** вопросы не повторяют задания уроков. Запрещено совпадение **фраз** (3 слова и больше) — польских вариантов и польских фраз вопроса — с текстами заданий и примеров уроков (после нормализации регистра, пробелов и пунктуации); отдельные слова и короткие сочетания разрешены, иначе пришлось бы избегать всей базовой лексики, которой учит приложение (моё решение по вопросу проверяющего). Проверка — тестом по контенту приложения.
- **Не угадываются исключением — правила для автора и автопроверка:**
  - все варианты одной грамматической формы и одной темы (четыре фразы одного шаблона, четыре формы одного слова, четыре предлога в одной фразе);
  - неверные варианты — типичные ошибки носителей украинского и русского: падежное окончание, вид глагола, предлог, ложный друг переводчика, похожее слово;
  - нет вариантов «не по теме», «всё перечисленное», явно грубых;
  - длины вариантов близки (автопроверка: самый длинный не длиннее самого короткого больше чем в 1,6 раза — эвристика, исключения помечаются в вопросе с причиной);
  - ровно один верный вариант (второй вариант-синоним — частая ошибка; проверяет автор, а пояснение должно объяснять, почему остальные неверны);
  - пояснение помещается в подпись вместе с вопросом (автопроверка длины на всех языках).
- **Картинки:** у каждого вопроса — картинка по смыслу (поле `image`) из **16 полноразмерных сцен**: bar mleczny, biuro, cukiernia, Lidl, lotnisko, mieszkanie, pierniki, pierogarnia, PKP, przychodnia, recepcja w górach, Stop Cafe, tramwaj, urząd, Stare Miasto, zapiekanki. Пять кадров магазинов (Żabka, Biedronka, Rossmann, InPost, ORLEN) — временные увеличенные вырезки; 2026-10-27 они сняты из Telegram проверкой качества (`scene-art.test.ts`) и в вопросы дня **не идут**, пока нет полноразмерных версий (моё решение; на макете для наглядности стоит Żabka). Вопросы грамматики и общения без «места» получают нейтральные сцены (mieszkanie, biuro, Stare Miasto, Stop Cafe). Автопроверка: у каждого вопроса есть картинка, файл существует; список «вопрос → картинка» для глаз владельца — в админке. JPG-копии сцен для бота делаются скриптом сборки рядом с существующими (`public/bot/scenes/`).

### Админка: новая страница «Вопрос дня» (SUPERADMIN и SUPPORT; менять план и запускать — только SUPERADMIN)

- **Вкладка «План» — запланированные публикации** (решение владельца: видеть все до запуска). Список дней на 30 дней вперёд: дата и время отправки, по каждому уровню — картинка, вопрос, варианты с отмеченным верным, пояснение (на языке по выбору: ru / uk / en), «как увидит игрок» (макет сообщения). Действия по каждому будущему дню: «Заменить вопрос» (выбор из банка с подсказкой: уровень, тема, когда был последний раз), «Сменить картинку» (из 16 сцен), «Пропустить день» (в этот день рассылки нет — людям приходит обычное напоминание), «Прислать себе». Прошедшие дни — только просмотр со статистикой.
- **Запуск:** вверху — состояние «Рассылка вопроса дня: выключена» и кнопка «Запустить с <дата>» (окно подтверждения: сколько человек получат, время, сколько примерно займёт отправка) и «Остановить». Пока владелец не нажал «Запустить», ничего не отправляется. Время рассылки меняется здесь же. Запуск, остановка и изменения плана — в журнал действий.
- **Вкладка «День» — как прошла рассылка** (по умолчанию сегодня, стрелки «вчера / завтра нет»): по каждому уровню — карточка: вопрос (ru), миниатюра картинки, отправлено, дошло, не дошло (заблокировал бота / ошибка), ответили (N и %), верно (N и % от ответивших).
- **Таблица получателей за день:** игрок (ссылка на карточку), уровень, язык, когда отправлено, доставка (дошло / заблокировал бота / ошибка доставки / ещё не отправлено), ответил (время) или нет, что выбрал (текст варианта), верно ✓ / неверно ✗. Отбор: все / ответили / не ответили / ошиблись / не дошло. Постранично.
- **Вкладка «Вопросы»:** весь банк — уровень, тема, вопрос, картинка, сколько раз был вопросом дня, сколько раз отвечали, % верно, выключатель. Сортировка по % верно: слишком лёгкие (≥ 90 %) и подозрительные (≤ 15 % — возможно, ошибка в вопросе) видны сверху.
- **Карточка игрока:** блок «Вопросы дня» за последние 14 дней (дата, вопрос, ответил ли, верно ли).
- **Проверить на себе:** кнопка «Прислать сегодняшний вопрос себе» (Telegram ID / @username, как в «Рассылках»).
- Выключение вопроса пишется в журнал действий.

### Включение

- Рассылка выключена, пока владелец не нажмёт «Запустить» в админке (после просмотра плана и пробного сообщения себе). Пока выключена — всё как сейчас (обычные напоминания и приглашения к `/quiz`). «Остановить» в админке возвращает всё как было со следующего запуска cron; отправленные сегодня сообщения остаются у людей.

## Что остаётся разработчику

- Схема хранения: таблица плана (день × уровень → вопрос, картинка, пропуск), состояние рассылки (включена, время, с какого дня), выключатель вопросов, отказ по Telegram ID, серия дней, «нет чата с ботом»; связь доставки с раундом (`bot_quiz_rounds`), миграция.
- Как поднять пропускную способность для рассылки всем (частота cron, бюджет за запуск) без превышения лимитов бесплатного Worker.
- Точный выбор вопроса по дате и правило «не та же картинка, что вчера».
- Тексты сообщений на uk / ru / en в тоне Бобека (как `copy.ts`).
- Учёт бюджета Bot API в cron вместе с напоминаниями и рассылками.
- Тесты: отправка вместо напоминания, одно сообщение в день, ответ один раз, процент по уровню, выключатель вопроса, возврат к напоминанию после 3 пропусков, проверки качества банка (форма, длины, «не из приложения», картинки, длина подписи), страница админки в браузере с axe.
