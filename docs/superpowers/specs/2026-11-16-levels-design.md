# Свой уровень на общей дороге: входной тест A0–B2 и версии уроков (2026-11-16)

Владелец: «Нужно проверить входной тест. Нельзя чтобы он был слишком лёгким, чтобы методом исключения можно было понять ответ. Вопросы должны быть уровня A0, A2, B1 и B2… Мы должны определить реальный уровень человека… Сейчас нам особенно важно не потерять пользователей, которые уже знают основы польского». На вопрос о перескоке городов: «Перескакивать не вариант, нужно чтобы человек начинал там же, где и все, но вопросы чтобы у него были его уровня». Сроки (2–3 недели, первый эффект через 3–4 дня) — «Начинай».

## Что было
- Тест: 10 вопросов уровня A0–A1, по 3 варианта; 8 из 10 решаются через русский/украинский (siedem → семь, pięć biletów → пять билетов, byłem → был). Итог — только A0 или A1; при хорошем результате открывались три первых города.
- Маршрут: 20 городов по 8 уроков (A1 ×7, A2 ×5, B1 ×5, B2 ×3). У урока одна версия заданий — уровня города. Знающий B1 проходит 80+ уроков своего уровня и ниже.

## Цели
1. Все начинают в Варшаве; задания урока — уровня игрока (не ниже уровня города).
2. Входной тест определяет уровень A0–B2 и не решается через родной язык и методом исключения.
3. Уровень подстраивается по ходу: легко — выше, трудно — ниже; игрок может выбрать уровень сам.

## Не цели этого этапа
- Сами трудные версии уроков (этап 2: Варшава, Лодзь, Краков; дальше — по городам).
- Учебная программа (алфавит, звуки, последовательность грамматики) — отдельный проект после этапов уровней.
- Перескок городов (владелец против).

## Анти-цели
- Знающий снова видит уроки «для новичков» без возможности поднять уровень.
- Тест, который можно пройти через русский язык или по длине варианта.
- Новичок, которого тест или автоподстройка ошибочно отправили на B1.

## Как устроено (решения)
- **Уровень заданий** — `player_progress.study_level` (A2 | B1 | B2 | NULL). NULL — обычные версии (уровень города). Ставят: входной тест (A2+), сам игрок в настройках, автоподстройка.
- **Версии урока** — колонка `exercises.level` (NULL — обычная версия; A2/B1/B2 — трудная). В контенте: `LessonSeed.levels = { A2?: […], B1?: […], B2?: […] }`; порядок 100+/200+/300+, идентификаторы как у обычных (`exerciseId(slug, order)`), счётчик `lessons.exercise_count` считает только обычную версию.
- **Выбор при старте урока** (обычный урок и экзамен города): если уровень игрока выше уровня урока — берётся версия с наибольшим уровнем, не выше уровня игрока; нет такой — обычная. Урок показывает уровень выбранной версии.
- **Автоподстройка** (только если `study_level` задан): урок версии своего уровня с точностью ≥ 90 % — +1 к «серии вверх», < 50 % — +1 к «серии вниз», иначе обе обнуляются. Три «вверх» подряд — уровень +1 (до B2); две «вниз» — уровень −1 (A2 → обычные версии). Игрок видит, что сложность изменилась.
- **Входной тест v2** — новый урок `placement-test-v2` (старый `placement-test` в архив). Блоки A0, A1, A2, B1, B2 по 3 вопроса (15 максимум). Блок сдан — 2 из 3. Блок не сдан — тест заканчивается (оставшиеся вопросы закрываются как пропущенные). Уровень = последний сданный блок (ни одного — A0). Уровень A2+ записывается в `study_level`. Города не открываются: все начинают в Варшаве.
- **Вопросы теста**: варианты — польские формы одного слова или «ложные друзья» (sklep ≠ склеп, zapomnieć ≠ запомнить), ловушки русской логики (moje mieszkanie, poszłam), чтение букв (ł, szcz); у каждого вопроса кнопка «Не знаю» (ответ не засчитывается, угадывать не нужно). Без вариантов-переводов, которые находятся по корню.
- **Знающие из нынешних игроков**: карточка на главной «Знаешь польский? Пройди тест уровня» для тех, у кого нет `study_level` и кто не проходил тест v2; уровень можно выставить в настройках.

## План работ этапа 1
1. shared: `variantLevel(lessonCefr, studyLevel, available)`, `placementResult(blocks)`, `adaptLevel(state, accuracy)` + тесты.
2. Миграция 0023: `exercises.level`, `player_progress.study_level`, `level_up_run`, `level_down_run`; триггеры счётчика — только `level IS NULL`.
3. Контент: `levels` в `LessonSeed`, `level` в задании; сид; входной тест v2 (15 вопросов), архив старого.
4. Сессии: выбор версии; тест v2 (порядок по блокам, остановка, «Не знаю», итог); автоподстройка; `/me` отдаёт `studyLevel`; `PATCH /me/study-level`.
5. Приложение: «Не знаю», остановка теста, без повторов ошибок в тесте, итог теста, уровень версии в уроке, сообщение о смене сложности, выбор уровня в настройках, карточка теста на главной.
6. Проверки: тесты сервера (тест v2, выбор версий, автоподстройка, угадываемость вопросов теста), браузерная проверка.
