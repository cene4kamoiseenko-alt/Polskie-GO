# Визуальное обновление: графика и серия игрока

Рабочие изменения без деплоя. Серверные правила, награды, цены и сохранения не изменены.

## Что изменено

- На главной и в профиле — карточка «Твой ритм»: оригинальный 2.5D-огонь `icons/streak.webp`, текущая серия и рекорд с сервера, фактическая активность последних семи дней, сегодняшнее состояние и переход к урокам.
- Отметки 3/7/14/30/60/100 и далее каждые 100 дней — только визуальные ориентиры, без новой валюты, предметов и бонусов. Дневная цель XP и серия остаются разными механизмами.
- Календарь использует даты из `/api/me/stats?days=7`, рассчитанные сервером в часовом поясе игрока. Пустые данные не заменяются выдуманной историей; предусмотрены загрузка и повтор запроса. Защищённый Premium день не выдаётся за день занятий.
- Корона Premium, щит уровня и иллюстрация выпускника используют готовые WebP. Маленький размер больше не переключает существующий растр на SVG. Неактивные GameIcon используют тот же WebP с обесцвечиванием.
- Пять разделов нижней навигации используют авторские растры: дом, карта, уроки, квесты, профиль. Выбранный пункт сохраняет подпись, плашку и индикатор, чтобы состояние было видно без распознавания цвета.
- Для достижений с готовым растром убрана рисованная SVG-оболочка: показывается сам авторский арт. Редкость выделяется свечением, закрытые состояния — обесцвечиванием и служебным замком.
- В предметах `gift`, `headphones`, `speech`, `map` подключены соответствующие готовые растры. Другие учебные изображения не заменены общими иконками: это могло бы исказить значение слова.
- На главной удалён CSS-рисунок деревянного указателя: название города оформлено текстовой подписью поверх авторской панорамы.
- RU/UK/EN, поддержка системного и пользовательского ограничения анимаций. Анимация огня короткая, без постоянного мерцания.

Это обновление общих компонентов, главной и профиля, а не завершённый редизайн всех экранов приложения.

## Недостающая графика — отдельное задание

Новые иллюстрации должны соответствовать имеющимся WebP: мягкий объём 2.5D, фактурные материалы, тёплый свет сверху слева, согласованная модель Бобека. Никаких примитивных SVG, CSS-рисунков или вырезанных случайных фрагментов вместо нужного предмета.

| Набор | Что требуется | Формат |
|---|---|---|
| Служебные игровые иллюстрации | `gamepad`, `sprout`, `clock`, `plane`, `lock`; отдельные серебряная и бронзовая медали | PNG/WebP с альфой, мастер 512×512, доставка 128/256 |
| Разделы без собственного растра | повторение, ошибки, таймер, скорость, друзья, настройки; отдельная домашняя иконка для нижней навигации | тот же свет и масштаб, мастер 512×512; проверить читаемость при 24/48 px |
| Сезонные значки | рогалик, рождественский подарок, билет, пончик, сердце, пасхальное яйцо, велосипед, польский флаг, солнце | отдельные объёмные значки без текста, 512×512; не подменять хлебом, картой или поездом |
| Учебные предметы | точные изображения из `ItemName` в `components/Illustrations.tsx`, кроме уже подключённых четырёх | каждый предмет отдельно, 512×512 с альфой; проверка соответствия польскому слову |
| Сцены без авторского растра | по инвентаризации `MissionScene` / `sceneArt`; нужен кадр конкретного места | 1536×1024 или согласованное со сценой соотношение; варианты 640/1200; без встроенных подписей |
| Квартира, будущая кастомизация | чистый фон, отдельные мебель/декор/тени/перекрытия и Бобек с общей камерой | единый холст 1536×1024, альфа, якоря и порядок слоёв; существующие сцены с впечённой мебелью для этого непригодны |

Оставшиеся старые SVG не означают готовый новый арт. Замена производится только после приёмки соответствующего ассета. Стрелки, галочки, закрытие и другие небольшие служебные контуры остаются средствами навигации.

## Проверка

Сборка: `npm run build -w @polski-go/web`.

Браузер: `node --import tsx scripts/visual-style-check.ts` (нужен Chromium Playwright). Стенд использует отдельную локальную D1 и тестового игрока: серии 0/7/30/100, ширины 320/390/430, фактические состояния календаря, загрузка огня и короны, отсутствие горизонтальной прокрутки, reduced motion, английский профиль в светлой теме. Снимки: `test-results/visual-style/`.

Настоящие Telegram WebView на iPhone и Android требуют отдельной проверки перед публикацией.

Результат локального прогона: сборка web прошла; браузер — 111 проверок без ошибок; `npm run assets` — 44 файла без ошибок; `git diff --check` — без замечаний. Проверены снимки главной в тёмной теме и профиля в светлой теме. Деплой не выполнялся.
