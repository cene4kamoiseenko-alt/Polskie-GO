# Свой уровень на общей дороге (2026-11-16)

Владелец: «Нельзя, чтобы входной тест был слишком лёгким… Мы должны определить реальный уровень человека… Важно не потерять пользователей, которые уже знают основы польского». И: «Перескакивать не вариант: человек начинает там же, где и все, но вопросы его уровня».
Проект: `docs/superpowers/specs/2026-11-16-levels-design.md`.

## Как это работает для игрока
- **Все начинают в Варшаве.** Города и сюжет у всех одни и те же.
- **Входной тест** определяет уровень A0–B2. До 15 вопросов: блоки по 3 вопроса — чтение букв (A0), A1, A2, B1, B2. Блок сдан при 2 правильных из 3; несданный блок заканчивает тест (новичок отвечает на 3 вопроса, B2 — на все 15). У каждого вопроса есть **«Не знаю»** — угадывать не нужно, ответ засчитывается как неверный, но выглядит спокойно, без «Неверно».
- **Уровень заданий.** Тест на A2 и выше ставит игроку уровень заданий: в уроках, где есть трудная версия, он получает её (тот же урок и сюжет, задания своего уровня). Ниже A2 — обычные версии.
- **Автоподстройка.** Если уровень задан: три урока своей версии подряд с точностью от 90 % — уровень выше (до B2); два подряд ниже 50 % — ниже (с A2 — обычные версии). На итогах урока игрок видит «Задания станут сложнее: уровень B2» или «Сделаем задания чуть проще».
- **Сам игрок** выбирает уровень в Настройках → «Уровень заданий»: По городу / A2 / B1 / B2, и там же может пройти тест.
- **Карточка на главной** «Знаешь польский? Пройди тест уровня» — тем, кто не начинает с нуля (самооценка не A0), не проходил новый тест и не выбрал уровень; «Скрыть» убирает её на этом устройстве.

## Почему старый тест не годился
10 вопросов уровня A0–A1, по 3 варианта; 8 из 10 решались через русский или украинский (siedem → семь, pięć biletów → пять билетов, byłem → был). Итог — только A0 или A1, хорошие результаты открывали три первых города.

## Как устроены вопросы теста (`apps/server/src/content/exams.ts`, `PLACEMENT_V2`)
- Варианты — польские формы одного слова (moje / moja / mój; większe / większy / więcej), без переводов, находимых по корню.
- «Ложные друзья»: sklep ≠ склеп, uroda ≠ уродство; идиомы (mieć muchy w nosie).
- Ловушки русской логики: «моя квартира» → moje mieszkanie; «пошла» → poszłam (а не poszła); «три года» → od trzech lat; «прошу о…» → proszę o przesłanie.
- Проверки (`apps/server/test/placement.test.ts`): у верного ответа «Вставь слово» минимум две похожие формы среди неверных; в переводе слова есть «созвучная» ловушка, а верный вариант звучит заметно меньше; верный ответ редко самый длинный.

### Что получает игрок
- Тот же урок, место и герои, но **своя теория**: объяснение и примеры версии заменяют обычные. Над теорией — плашка «Задания твоего уровня».
- Слова урока (карточки «новые слова») в версии не показываются: игрок этого уровня их знает.
- Пример, «Мой дом» (Краков): A2 — что где в квартире (**w kuchni, na balkonie** — местный падеж), B1 — аренда (**umowa najmu, media wliczone w czynsz**), B2 — юридический язык договора (**umowa najmu okazjonalnego, Strony ustalają, że…**).
- Практика и «Грамматика» берут задания версий не выше уровня игрока (`practiceVersions`). Счётчики в «Грамматике» считают только обычные задания.

### Как добавить версию урока
Версии лежат отдельно от уроков, по городам: `apps/server/src/content/levels/<город>.ts`, реестр — `levels/index.ts` (`LESSON_LEVELS`, ключ — slug урока):
```ts
const WAW2: LessonLevels = {
  A2: { explanation: t(uk, ru, en), examples: [{ pl, tr }], exercises: [...] },
  B1: { ... },
  B2: { ... },
};
export const WARSZAWA_LEVELS = { 'waw-2-uprzejmosc': WAW2, ... };
```
- `withLevels` в `seed.ts` подставляет версии в уроки по slug. Опечатка в slug — ошибка сборки сида, а не тихо пропавшая версия.
- Те же построители заданий (`fillGap`, `reverseChoice`, `dialogue`, `build`…), тот же сюжет и место, грамматика и лексика уровня версии.
- **Без `listen` и `dictation`**: их озвучку делают в админке, а новые фразы версий ещё не озвучены.
- У `build` и `wordOrder` перечисляйте другие естественные порядки слов (`alternatives`): «Z powodu awarii pociąg został odwołany» — тоже верно.
- В БД версия получает порядок 100+/200+/300+ и `exercises.level`, теория — в `lessons.level_texts` (миграция 0024). Сид всегда обновляет теорию из кода и очищает её у уроков, где версий больше нет.
- Счётчик «N заданий» на карточке урока считает только обычную версию (порядок < 100). Ошибка, найденная в этапе 2: пересчёт в конце сида считал и версии (12 → 39); исправлено.
- Игрок получает наибольшую версию не выше своего уровня (B2 без версии B2 — версию B1; уровень ниже версии — обычную).
- Версия бывает только **выше уровня урока** (`variantLevel`): уроку A1 нужны A2, B1, B2, уроку A2 — B1 и B2, уроку B1 — B2. Версию на уровне урока или ниже игрок не получит никогда — проверка это запрещает.

### Правила качества (проверяются кодом)
- `test/lesson-levels.test.ts`: в городах из списка `COVERED` у каждого урока и босса есть все версии выше его уровня, и нет версий на его уровне или ниже; в версии от 8 заданий и от 4 типов; своя теория на трёх языках; у заданий с выбором минимум 3 варианта без повторов; варианты и реплики без перевода — только польский текст (их видят игроки на любом языке, и они уходят в озвучку: транскрипция «[madry] — «мадри»» ломала и то и другое); у «Вставь слово», «Перевод слова», «Найди ошибку» и «Чтения» есть объяснение; задания версий не повторяют друг друга и обычный урок; верные ответы принимаются проверкой; лишние плитки не совпадают со словами ответа; альтернативы состоят из тех же слов.
- `test/city-quality.test.ts` проверяет версии тем же детектором угадываемости, что и обычные уроки (`lessonVersions` в `quality.ts`): одинаковое начало у всех неверных, самый длинный верный, доля диалогов, где верная реплика самая длинная (не больше половины).
- `test/quiz-bank.test.ts`: фразы версий не повторяют «Вопрос дня».
- Остальное — как для всех заданий (`docs/EXERCISE_QUALITY.md`): ответ не угадывается без знания языка.
