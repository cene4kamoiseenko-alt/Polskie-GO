# Удержание: аудит напоминаний, серий, возвращения и аналитики (2026-11-14)

Запрос владельца: «Проверь удержание». Проверено чтением кода и тестами; настоящий Telegram (iPhone, Android), боевая база и боевые Cloudflare/Telegram-лимиты отсюда не проверялись — это отмечено там, где важно.

## 1. Что есть и работает

**Напоминания в боте** (`apps/server/src/jobs.ts`, cron каждые 15 минут):

- Время выбирает сам игрок при знакомстве (по умолчанию 19:00); выбранное время = согласие на сообщения (`notifications_enabled`). Гостям вне Telegram (telegram_id < 0) не шлём: бота у них нет.
- Час и день считаются в часовом поясе игрока; невалидный пояс пропускается, а не роняет запуск; день — по `dayKey(now, tz)`.
- Не чаще раза в день: уникальный ключ `notification_log (user, kind, day)` — параллельный запуск пропускает того, кого уже «захватили»; не шлём тем, кто сегодня уже занимался.
- Три сценария по реальным данным: **урок** (серия 0–1), **серия** (≥ 2 дней, число берётся из `effectiveStreak`), **возвращение** (пауза ≥ 3 дней). Картинка, кнопка в Mini App, строка «/stop — выключить напоминания».
- Доставка без «ложного отправлено»: явный отказ Telegram (429, 5xx) повторяется до 3 раз в тот же местный день и только пока игрок согласен и ещё не занимался; результат неизвестен (тайм-аут, обрыв) — **не повторяется** (лучше пропустить день, чем отправить дважды); 403 — «молчим 30 дней».
- Вопрос дня и напоминание не складываются: пока идёт рассылка вопроса, напоминание получают только те, кому вопрос не придёт (тест `daily-quiz.test.ts`) — одно сообщение в день.

**Серия** (`packages/shared/src/progression.ts`, `services/rewards.ts`):

- Считается по местному дню игрока. Любой завершённый сеанс (урок, повторение, «Мои ошибки», «5 минут», миссия) продлевает серию — даже непройденный урок: сам факт занятия важнее оценки.
- Смена часового пояса не сжигает серию (`shiftLastDayForZone`); день «из будущего» не ломает счёт.
- Щит Premium закрывает один пропущенный день не чаще раза в неделю (`STREAK_SHIELD_DAYS`).

**Возвращение:** напоминание «Dawno się nie widzieliśmy» после 3 дней паузы, достижение за урок после ≥ 7 дней.

**Аналитика в админке:** воронка новичков (зарегистрировался → знакомство → урок → вернулся на следующий день → Premium), источники, входной тест, напоминания по дням (отправлено / не доставлено / бот заблокирован / пропущено), «Возвращаются» (D1 / D7 / D30 по дню регистрации в Варшаве) и таблица по неделям регистрации.

| № | Дефект | Последствие | Исправление |
|---|---|---|---|
| 1 | После ответа Telegram 403 («бот заблокирован» **или** «бот не может начать разговор») молчание держалось ровно 30 дней при любых обстоятельствах | Игрок, открывший Mini App по прямой ссылке (бот ему ещё писать не мог), получал одну неудачную попытку и затем целый месяц тишины — даже если сразу нажимал Start у бота или заново выбирал время напоминания | **Сделано.** `bot/mute.ts`: молчание снимается, как только игрок **написал боту** (`bot_contacts.last_seen_at` позже отказа) или **сохранил настройки** (`user_settings.updated_at` позже отказа); пока бот помечен заблокированным (`bot_contacts.blocked_at`), попыток нет вовсе. Новый отказ — новая тишина (одна лишняя попытка, а не месяц). Тот же код — у приглашений к быстрым вопросам. Тесты: `reminders-delivery.test.ts` (4), `bot-quiz.test.ts` (1) |
| 2 | Приложение нигде не просило у Telegram разрешение боту писать в личку (`requestWriteAccess`) | У игроков без Start у бота напоминания не доходили в принципе | **Сделано.** `lib/telegram.ts`: `requestBotWriteAccess()` — один запрос в момент, когда игрок сам выбрал время напоминания (шаг «Напоминание» знакомства, включение в настройках); отказ ничего не ломает, интерфейс не ждёт дольше минуты. В настройках сохранение идёт после окна — оно же снимает прежнюю «тишину». **Не проверено в настоящем Telegram** (в браузерной проверке `requestWriteAccess` нет — клиент считает «можно») |
| 3 | «Возвращаются D1/D7» считалось по дате UTC, а активность игрока хранится по местному дню; D7 был «в любой день с 7-го» | Регистрации в первые часы местных суток давали ложное «вернулся» (активность в день регистрации засчитывалась как D1); D7 завышен | **Сделано.** `services/admin-insights.ts` → `retentionReport`: один расчёт по дню регистрации в Варшаве, точные D1, D7 и D30; день входит в основу, только когда он уже закончился; плюс таблица «Удержание по неделям регистрации» на «Обзоре» (8 недель, «—» пока день не наступил, «*» если в основе меньше 10 игроков). Тест `retention.test.ts` |

## 3. Ограничения, которые нужно знать (не дефекты сегодня)

- **Пропускная способность.** За один запуск cron (раз в 15 минут) уходит не больше 35 вызовов Bot API, из них часть занимают самопроверка бота и рассылки из админки. На практике это порядка 100–140 напоминаний в час на всех. Игрок, до которого не дошла очередь за свой час, в этот день напоминания не получит. Для сотен игроков хватает; при тысячах с одинаковым часом (а 19:00 выберет большинство) понадобится: (а) поднять бюджет, если у Cloudflare Workers платный план (лимит 35 подзапросов рассчитан на бесплатный), (б) разрешить «догонять» в течение 2–3 часов после выбранного, (в) подключить минутный cron, который сейчас занят только вопросом дня. Какой тариф у Cloudflare, неизвестно — решает владелец.
- **Telegram может не дать писать** тем, кто не нажимал Start (см. дефект 2): число таких игроков видно в админке в «Аудитории бота» и по доле «заблокирован» в напоминаниях.
- **D1 «на следующий день»** для зарегистрированных сегодня не определён — их нет в знаменателе.

## 4. Чего нет — предложения (без решения владельца не делаю)

1. **Вариант «Б» для напоминаний** (ждёт решения владельца): после N подряд проигнорированных напоминаний — реже, затем пауза; сегодня для напоминаний о уроке такого нет (у приглашений к быстрым вопросам есть `IGNORED_MAX`).
2. **Заморозка серии для всех** (сейчас — только щит Premium): например, один «выходной» в неделю бесплатно. Влияет на экономику Premium.
3. **Недельный итог** (в приложении или в боте): сколько уроков, слов, XP за неделю и сравнение с прошлой.
4. **Возвращение внутри приложения**: приветствие после паузы («Серия сгорела — начни новую») сегодня только в напоминании бота; в самом приложении после паузы ничего не меняется.
5. **Напоминания вне Telegram** (Android, гости): сейчас не приходят совсем; нужны push-уведомления (Web Push/FCM) и согласие игрока.
