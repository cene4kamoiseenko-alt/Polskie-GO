# Недельная лига (вариант А, 2026-11-15)

## Почему переделали
Раньше игроки делились на четыре лиги по опыту **за всё время** (Бронза до 500 XP, Серебро до 2000, Золото до 5000, Алмаз), и каждый видел только свою. Активных игроков пока десятки, поэтому в лиге было 3–5 человек, а в понедельник таблица пустела. После урока рейтинг не обновлялся (приложение не сбрасывало сохранённый список). За места ничего не давали.

## Правила
- **Одна общая таблица недели** для всех. В неё попадает тот, кто набрал за неделю **от 20 XP** (примерно один урок). Кто меньше — видит себя отдельно и подсказку «Набери ещё N XP».
- **Неделя — по Варшаве** для всех: с понедельника 00:00 до воскресенья 23:59.
- **Порядок:** XP за неделю; при равенстве выше тот, кто набрал раньше.
- **Значок лиги** (Бронза / Серебро / Золото / Алмаз) остаётся у имени — он по опыту за всё время, как раньше.
- Скрывшие себя из рейтинга (настройки) и заблокированные — не в таблице и без призов.

## Призы
| Место | Złotki |
|---|---|
| 1 | 300 |
| 2 | 200 |
| 3 | 100 |
| 4–10 | по 25 |

Приз выдаётся, только если за неделю набрано **от 100 XP**. Места не сдвигаются: если, например, 10-е место набрало 90 XP, его приз просто не выдаётся.

## Как начисляется
- В понедельник ночью фоновая задача (раз в 15 минут) подводит прошедшую неделю один раз: Złotki в кошелёк (журнал `wallet_transactions`, причина `league_prize`, ключ `league:<неделя>:<игрок>`), строки `league_awards`, отметка `league_weeks`. Повторный запуск ничего не меняет.
- **Бот** пишет призёру: «Итоги недели: твоё место — 2 (640 XP). Награда +200 zł уже в кошельке» с кнопкой «Открыть рейтинг». Как у напоминаний: только тем, кому бот может писать. Поздравление — только со свежими итогами (до 3 дней).
- **Не ночью** (владелец, 2026-11-15): Złotki приходят сразу после подведения итогов, а сообщение бот шлёт только днём по времени игрока — с 9:00 до 21:00 (пояс из настроек игрока, по умолчанию Варшава). Для Польши это понедельник, 9:00. Ночью призёр просто пропускается и получает поздравление утром (`LEAGUE_NOTIFY_HOURS`, `apps/server/src/services/league.ts`).
- **В игре** при входе — окно «Место N в рейтинге недели!» с суммой. После закрытия не всплывает.
- **Постер в чате** (владелец, 2026-11-15): призёру 1–3 места бот присылает картинку своего места с подписью и кнопкой «Открыть рейтинг». На постере надписи на языке игрока: **русский** интерфейс — русский постер, **украинский** — украинский; английский интерфейс и места 4–10 — текстом. Если Telegram не принял фото, уходит тот же текст сообщением. Файлы: `apps/web/public/bot/league/{ru,uk}/place-{1,2,3}.jpg` (1080 px по ширине, исходники — `docs/design/league/bot/`).

## На экране «Рейтинг»
Счётчик до конца недели, полоса призов, в карточке игрока — главное для него сейчас («Набери ещё 8 XP», «Для приза нужно от 100 XP», «Сейчас твой приз: +25 zł · До 3-го места: 120 XP»), значок лиги и приз у каждой строки, победители прошлой недели.

## Вид экрана (растр владельца, 2026-11-15)
Векторные щиты, лавр, флаги и силуэты города заменены деталями владельца (`docs/design/league/ui`, сборка `node scripts/build-league-art.mjs` → `apps/web/src/assets/league/`):
подиум — три пьедестала с медалью места в медальоне и короной над аватаром, на фоне вечернего Кракова; медали 1–3 в строках, карточке игрока и победителях прошлой недели; щит лиги; кубок; Бобек с кубком у призов; во вкладке «Друзья» — Бобек с телефоном и три преимущества с иконками.
Готовые макеты из архива (подиум с именами, карточка «Сенечка», строки игроков, заголовок «Рейтинг ліги», кнопка «Запроси друга») не используются: в них вписаны конкретные имена и украинский текст, а экран показывает живые данные на трёх языках.

## Приглашение друга (вкладка «Друзья», 2026-11-15)
Раньше кнопка «Пригласить друга» отправляла голую ссылку с текстом. Теперь другу приходит **картинка владельца с подписью и кнопкой «Играть вместе»** (ссылка с реферальным кодом, открывает игру):
- русский интерфейс — «Учи польский с Бобеком!», украинский — «Вивчай польську з Бобеком!» (на обеих ещё и по-польски), английский — стартовая картинка бота без надписей;
- как это устроено: сервер сохраняет у бота готовое сообщение (Bot API `savePreparedInlineMessage`, `POST /api/friends/invite/prepare`), приложение отдаёт его в `Telegram.WebApp.shareMessage` — Telegram сам показывает выбор чата, сообщение уходит от имени игрока с пометкой «via @бот»;
- старый Telegram (до Bot API 8.0), вход вне Telegram или ошибка — уходит прежняя ссылка; закрыл окно выбора чата — ничего не происходит;
- в карточке приглашения справа — миниатюра той же картинки (вместо вырезанного Бобека с телефоном: у вырезки были рваные края).
Файлы: `apps/web/public/bot/invite/{ru,uk}.jpg` (исходники `docs/design/invite/`), `apps/server/src/services/invite.ts`, `apps/web/src/lib/invite.ts`, тест `apps/server/test/invite.test.ts`.

**Совет владельцу:** чтобы и обычная ссылка `t.me/PolskieGoo_bot/app` показывала картинку (например, когда её копируют вручную), в @BotFather → `/myapps` → приложение → *Edit Photo* можно поставить картинку приложения — Telegram подставит её в превью ссылки.
