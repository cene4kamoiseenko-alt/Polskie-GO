# Google Text-to-Speech: пошаговое подключение польской озвучки

Состояние на 2026-10-27. Для владельца проекта, без программирования: всё делается в браузере (Google Cloud Console, Cloudflare, админка приложения).

**Что сделал я:** подготовил код, лимиты расходов, панель сравнения голосов в админке и эту инструкцию.

**Чего я не делал:**

- не создавал проект Google Cloud;
- не подключал оплату;
- не отправлял ни одного платного запроса;
- голоса на слух не оценивал;
- на телефонах не проверял.

Всё это делаете вы, по шагам ниже. Распознавание речи (STT) этой работой не менялось. Его настройка — в `docs/AUDIO_SETUP_RU.md`.

## 0. Коротко: что получится и сколько стоит

**Цены Google** — официальная страница https://cloud.google.com/text-to-speech/pricing, проверено 2026-10-27. Перед подключением оплаты сверьте ещё раз.

| Тип голоса | Бесплатно в месяц | Дальше |
|---|---|---|
| Chirp 3: HD (самые живые голоса, 30 польских) | 1 млн символов | $30 за 1 млн |
| WaveNet (`pl-PL-Wavenet-F`, `-G`) | 4 млн символов | $4 за 1 млн |
| Standard (`pl-PL-Standard-F`, `-G`) | 4 млн символов | $4 за 1 млн |

Google считает каждый символ фразы, включая пробелы. По словам Google, **платёжный аккаунт обязателен даже для бесплатного объёма**, а сверх него деньги списываются автоматически.

**Объём нашего контента** — около 4000 польских фраз, около 81 400 символов на одну скорость. Озвучка всего курса на обычной и медленной скорости — около 163 000 символов:

- Chirp 3: HD — $0 в пределах бесплатного миллиона (≈ $4,9, если миллион уже израсходован);
- WaveNet — $0 (≈ $0,65 сверх бесплатного объёма).

Это разовая трата. Озвученная фраза хранится в базе, и повторные прослушивания бесплатны для всех игроков. Платят только за **новые** фразы.

**Защита от расходов, которая уже работает в приложении:**

| Защита | По умолчанию | Где меняется |
|---|---|---|
| Новых фраз на одного игрока в сутки | 300 | переменная `TTS_DAILY_LIMIT` |
| Символов платной озвучки на всех игроков в сутки (UTC) | 30 000 (≈ 930 000 в месяц — в пределах бесплатного миллиона Chirp 3: HD) | переменная `TTS_GLOBAL_DAILY_CHARS` |
| Аварийный выключатель | — | переменная `TTS_PROVIDER` = `off` |
| Какой текст можно озвучить | только латиница, цифры и знаки препинания. Сравнение голосов в админке — только фразы теста и курса | в коде |
| Озвучка всего курса | только кнопкой в админке, после окна с ценой | — |

Сверх суточного лимита приложение не обращается к Google, и игрок слышит польский голос телефона. Чужой голос не используется никогда. Лимит сбрасывается в 00:00 UTC (02:00 по Варшаве летом, 01:00 зимой).

**Защита ключа.** Ключ хранится только в секретах Cloudflare Worker и уходит в Google заголовком запроса, а не в адресе. В приложение, в ответы сервера и в админку он не попадает. Это проверяют тесты `apps/server/test/tts-cost.test.ts` и `tts-provider.test.ts`.

## Шаг 0. Посмотреть, что играет сейчас

Админка → «Огляд» → блок «Польська озвучка контенту»:

- **«Зараз грає: голос пристрою»** — серверной озвучки нет, ключа нет. Идите по шагам 1–9.
- **«Зараз грає: google · pl-PL-Wavenet-A»** и красное «голосу немає в офіційному списку» — ключ уже есть, но голос по умолчанию устарел. Google мог перестать его синтезировать; признак — «Остання помилка провайдера: http_400». Начните с шага 7 (сравнение), затем шаг 8.

## Шаг 1. Проект Google Cloud

1. Откройте https://console.cloud.google.com и войдите Google-аккаунтом, который будет владельцем.
2. Вверху — выбор проекта → **New project**. Имя — `polski-go`, остальное по умолчанию → **Create**.
3. Убедитесь, что вверху выбран именно `polski-go`.

## Шаг 2. Платёжный аккаунт — ваше решение

Без него Text-to-Speech не работает. Есть два варианта:

- **Бесплатный пробный период (Free Trial).** Новым аккаунтам Google даёт $300 на 90 дней. По правилам Google (https://docs.cloud.google.com/free, https://support.google.com/cloud/answer/7006543) деньги в пробный период **не списываются, пока вы сами не нажмёте «Upgrade»** до платного аккаунта. Когда кредит или 90 дней кончатся, озвучка перестанет синтезировать новые фразы. Уже озвученное продолжит играть из базы. Этого хватит, чтобы сравнить голоса и озвучить весь курс.
- **Платный аккаунт.** Работает без срока. Сверх бесплатного объёма деньги списываются с карты автоматически, но наши лимиты из раздела 0 держат расход в бесплатном объёме Chirp 3: HD.

Как подключить: меню ☰ → **Billing** → **Link a billing account** (или **Create account**) → данные карты.

## Шаг 3. Бюджет и оповещения — до включения API

1. ☰ → **Billing** → **Budgets & alerts** → **Create budget**.
2. Projects: `polski-go`; Services: Cloud Text-to-Speech API (или все).
3. Сумма: например **$5**. Оповещения на 50 %, 90 % и 100 % — на вашу почту.

Бюджет Google **только присылает письма и не останавливает расходы**. Останавливают лимиты приложения (раздел 0) и выключатель `TTS_PROVIDER=off`.

## Шаг 4. Включить Cloud Text-to-Speech API

☰ → **APIs & Services** → **Library** → в поиске «Cloud Text-to-Speech API» → **Enable**.

## Шаг 5. Создать API-ключ и ограничить его

1. ☰ → **APIs & Services** → **Credentials** → **+ Create credentials** → **API key**. Ключ появится в окне. Скопируйте его и **никуда не пересылайте**: ни в Telegram, ни в чат, ни в GitHub, ни на скриншоты.
2. Нажмите **Edit API key** (или имя ключа в списке):
   - **API restrictions** → **Restrict key** → отметьте только **Cloud Text-to-Speech API** → **Save**;
   - **Application restrictions** оставьте **None**. У Cloudflare Worker нет постоянного IP, а в браузер игрока ключ не попадает.
3. Для распознавания речи (STT) лучше завести отдельный ключ (`docs/AUDIO_SETUP_RU.md`). Тогда отзыв одного не выключит другое.

## Шаг 6. Положить ключ в Cloudflare — сначала staging

**Вариант А: staging (рекомендую).** Staging — отдельная копия приложения, `docs/STAGING.md`. Озвучка для игроков там всегда выключена (`TTS_PROVIDER=off`, этого требует сторож staging), а сравнение голосов в админке staging работает. Так голоса слушаются, не трогая production.

1. Cloudflare Dashboard → **Workers & Pages** → `polskie-go-staging` → **Settings** → **Variables and Secrets** → **Add**.
2. Type: **Secret**, Name: `GOOGLE_TTS_API_KEY`, Value: ключ из шага 5 → **Deploy**.
3. Альтернатива — терминал: `npx wrangler secret put GOOGLE_TTS_API_KEY -c wrangler.staging.jsonc` (ключ вводится, на экран не выводится).

**Вариант Б: сразу production** (если staging не заведён). Порядок важен:

1. Сначала Cloudflare → `polskie-go` → **Settings** → **Variables and Secrets**: переменная `TTS_PROVIDER` = `off` → **Deploy**. Иначе в момент появления ключа приложение само включит Google с устаревшим голосом по умолчанию `pl-PL-Wavenet-A`.
2. Затем Secret `GOOGLE_TTS_API_KEY` → **Deploy**.

Игроки до шага 8 слышат голос телефона, как сейчас.

## Шаг 7. Сравнить голоса на слух

Админка (`…/admin/`) → «Огляд» → **«Порівняння голосів (на слух)»** → **Відкрити**.

1. Сразу выбраны 4 голоса: `Chirp3-HD-Kore` (ж), `Chirp3-HD-Charon` (м), `Wavenet-F` (ж), `Wavenet-G` (м). Список «Голоси для порівняння» — все 34 польских голоса Google, можно выбрать любые 4.
2. **Сліпий режим** включён: голоса подписаны A, B, C, D в случайном порядке. Названия открываются кнопкой «Показати, хто є хто» — нажимайте после оценки.
3. Слушайте:
   - **«Фрази тесту»**: 40 фраз, ★ — обязательные. Под каждой написано, что слушать: «w» перед словом, ł, ą/ę, sz/ś/cz, ударение, кавычки, диалоги. Кнопка 🐢 — медленная скорость.
   - Блоки **«З контенту»**: настоящие фразы курса, в которых синтезаторы чаще ошибаются. Это время (`10:30`), цены (`4,40 zł`), линии метро (`M2`), аббревиатуры (`PESEL`, `BLIKIEM`), сокращения (`ul. Freta`), числа, отдельные буквы.
4. Слушайте на телефоне — и через динамик, и в наушниках: в Telegram озвучку чаще слушают с динамика.
5. **Голос отклоняется**, если хотя бы раз:
   - «w» звучит как название буквы («wu» / «duże wu») во фразах с предлогом;
   - ł прочитано как русское «л»;
   - пропали носовые ą/ę;
   - прочитаны кавычки или тире;
   - время или цена прочитаны неверно (`10:30` как «десять двоеточие тридцать», `4,40 zł` как «четыре запятая сорок»);
   - медленная скорость с обрывами или металлическим звуком.

   Полный протокол — `docs/POLISH_TTS_BENCHMARK.md`, раздел 7.
6. Выберите основной голос и запасной — желательно другого типа (например, Chirp 3: HD и WaveNet).

**Цена сравнения.** Каждое первое прослушивание фразы данным голосом — платный запрос на символы этой фразы. Повтор берётся из базы и бесплатен. Весь тестовый набор четырьмя голосами на двух скоростях — около 7 200 символов. Вместе с фразами курса — меньше 30 000, то есть в пределах бесплатного объёма. Админка показывает «Сьогодні адмінка: N символів».

## Шаг 8. Включить выбранный голос

Production → Cloudflare → `polskie-go` → **Settings** → **Variables and Secrets**:

1. Если ключ ещё не добавлен (вы сравнивали на staging) — Secret `GOOGLE_TTS_API_KEY`. Можно тот же ключ.
2. Переменная `GOOGLE_TTS_VOICE` = имя выбранного голоса, точно как в списке, например `pl-PL-Chirp3-HD-Kore`.
3. Переменная `TTS_PROVIDER` = `google`. Должна стоять после того, как задан голос.
4. **Deploy**.

Проверка: админка → «Польська озвучка контенту» → «Зараз грає: google · pl-PL-… · chirp3-hd (TTS_PROVIDER=google)», без красных предупреждений.

## Шаг 9. Озвучить весь курс заранее (прогрев)

Та же панель → **«Озвучити весь контент»**. Окно покажет голос, сколько символов осталось озвучить и оценку цены — подтвердите. Курс озвучивается частями. Страницу не закрывайте до надписи «Озвучено N з N» (N — число фраз курса, около 4000).

После этого игроки получают готовые файлы из базы, и новые траты почти прекращаются. Платными остаются только фразы, добавленные в курс позже.

Смена голоса позже — снова шаги 8 и 9: новый голос = новая озвучка всех фраз по ценам раздела 0. Старые записи не мешают и новым голосом не выдаются.

## Шаг 10. Проверка на телефонах

Я не проверял ни на одном реальном устройстве — **НЕ ПРОВЕРЕНО**. Пройдите на iPhone и на Android, в Telegram (Mini App) и отметьте результат:

| Действие | Ожидается |
|---|---|
| Урок → кнопка 🔊 у слова | польский голос выбранного типа, без задержки больше 1–2 с |
| Кнопка 🐢 (медленно) | та же фраза медленнее, голос не «басит» и не «пищит» |
| Повторное нажатие той же кнопки | звучит сразу (из кеша) |
| iPhone с включённым беззвучным режимом (переключатель сбоку) | записать, звучит ли (поведение iOS для веб-звука различается) |
| Bluetooth-наушники | звук в наушниках |
| Свернуть Telegram во время озвучки и вернуться | звук не «застревает», следующая кнопка работает |
| Режим полёта после того, как фраза уже звучала | звучит из кеша телефона; новая фраза — голос телефона или понятная ошибка, не тишина без объяснения |
| Конструктор фраз: нажать отдельное «W» | не произносится «duże wu» |
| Настройки → проверка озвучки | показывает, что озвучка серверная |

## Шаг 11. Лимиты: поднять, опустить, выключить

Всё здесь — Cloudflare → Worker → **Settings** → **Variables and Secrets** → **Deploy**:

- **Больше игроков, мало новых фраз** — оставить как есть.
- **Поднять лимит на всех.** `TTS_GLOBAL_DAILY_CHARS`, например `100000`. Помните: 1 млн символов Chirp 3: HD в месяц бесплатно. При WaveNet бесплатно 4 млн — можно до `120000`.
- **Лимит на игрока.** `TTS_DAILY_LIMIT` (новых фраз в сутки).
- **Аварийно выключить озвучку** — `TTS_PROVIDER` = `off`. Игроки сразу слышат голос телефона, данные не теряются.
- **Ключ утёк** — Google Cloud → **APIs & Services** → **Credentials** → ключ → **Regenerate key** (или удалить и создать новый, шаг 5). Затем новый ключ в Cloudflare (шаг 6 или 8).

Расход за сегодня и за 30 дней виден в админке, строка «Платний синтез сьогодні»: отдельно игроки (с лимитом), отдельно админка (прогрев и сравнение). Точные списания — Google Cloud → **Billing** → **Reports**.

## Если что-то не работает

| Что видно в админке | Причина | Что сделать |
|---|---|---|
| «Остання помилка провайдера: http_403» | API не включён (шаг 4), ключ ограничен другим API (шаг 5) или нет платёжного аккаунта (шаг 2) | проверить три шага; в Google Cloud → APIs & Services → Cloud Text-to-Speech API должно быть «Enabled» |
| «http_400» | имя голоса с ошибкой или голоса нет у Google (например, `pl-PL-Wavenet-A`) | `GOOGLE_TTS_VOICE` — имя точно из списка «Порівняння голосів» |
| «http_429» | сработала квота Google (запросов в минуту) | подождать; при прогреве — нажать кнопку ещё раз, он продолжит |
| Игрокам вдруг голос телефона, в админке сегодня лимит исчерпан | сработал `TTS_GLOBAL_DAILY_CHARS` | ждать 00:00 UTC или поднять лимит (шаг 11) |
| «Порівняння голосів»: «Ключа провайдера немає» | ключ не в этом Worker (staging и production — разные) | шаг 6 для нужного Worker |
| «TTS_PROVIDER=off — серверну озвучку вимкнено» | так и задумано до шага 8 | шаг 8 |
