# Проверка интерфейса

1. `npm ci`
2. `npx playwright install chromium` (и зависимости браузера, если их требует система).
3. Остановить другие локальные серверы на 5173/8787.
4. `npm run e2e`

Проверка сама поднимает временную D1 через Miniflare, настоящий API и Vite, создаёт тестового пользователя и закрывает окружение в конце. Production не используется.

Сценарий: главная на 360/390/430 px; профиль, магазин, список уроков; продолжение первого урока на голосовом упражнении; повтор после имитации тишины без отправки неверного ответа; имитация распознанной фразы и её проверка реальным локальным API. Проверяются ошибки JS и горизонтальное переполнение. Скриншоты и JSON сохраняются в test-results/.

Для специальной CI-среды можно передать путь к уже установленному Chromium через PLAYWRIGHT_CHROMIUM_EXECUTABLE. В этой среде проверка выполнена таким способом с отдельным headless Chromium. Это настройка тестового запуска, а не зависимость приложения.

Важно: браузерная проверка имитирует события SpeechRecognition. Это не испытание физического микрофона, Telegram WebView или реального Azure STT/TTS. Такие сценарии проверяются отдельно на целевом устройстве.
