# Проверка интерфейса

1. `npm ci`
2. `npx playwright install chromium` (и зависимости браузера, если их требует система).
3. Остановить другие локальные серверы на 5173/8787.
4. `npm run e2e`

Проверка сама поднимает временную D1 через Miniflare, настоящий API и Vite, создаёт тестового пользователя и закрывает окружение в конце. Production не используется.

Сценарий: главная на 360/390/430 px; профиль, магазин, список уроков; продолжение первого урока на шаге «Повтори вслух»: микрофон и распознавание не вызываются (подменённые `getUserMedia` и `SpeechRecognition` считают обращения), клиент шлёт только `skipped`, сервер отвечает без зачёта и без XP, маршруты `/api/speech/*` отвечают 404. Проверяются ошибки JS и горизонтальное переполнение. Скриншоты и JSON сохраняются в test-results/.

Для специальной CI-среды можно передать путь к уже установленному Chromium через PLAYWRIGHT_CHROMIUM_EXECUTABLE. В этой среде проверка выполнена таким способом с отдельным headless Chromium. Это настройка тестового запуска, а не зависимость приложения.

Важно: проверок речи в приложении нет (с 2026-11-14), браузерная проверка лишь доказывает, что микрофон не запрашивается. Озвучка (TTS) и Telegram WebView проверяются отдельно на целевом устройстве.
