# Bobek V2 — независимые слои, пробный арт-риг (не production)

## Что создано
- Отдельный архив **BOBEK_V2_layered_art_draft.zip** в исходном чате с пользователем: 35 редактируемых SVG, 105 WebP (1024/512/256), 5 поз, 2 вида верхней одежды, рюкзак, кепка, очки, моргание.
- Чистый слой тела без вписанного худи; красное худи и синяя джинсовая куртка действительно имеют разные детали.
- `apps/web/src/dev/lookV2Manifest.ts` — версия `bobek-v2-art-draft@1`, совместимость с существующим `resolveLook`.
- `apps/web/src/dev/lookV2Assets.ts` — lazy Vite-ассеты с проверкой наличия обязательных изображений.
- `PreviewBobek.tsx` и `LookPrototype.tsx` — выбор графической модели на странице `/__look-prototype`; изолированный QA-режим во фронтальных состояниях.
- `scripts/import-bobek-v2.mjs` — проверенный импорт WebP с альфа-каналом и нормальными размерами.

## Как загрузить новые изображения
В репозиторий намеренно **не включены двоичные картинки чернового арта**: сначала нужно художественное подтверждение. После получения ZIP из чата:

```bash
unzip BOBEK_V2_layered_art_draft.zip -d /tmp/bobek-v2
npm ci
npm run bobek:v2:import -- /tmp/bobek-v2/bobek_v2_assets
npm run typecheck
npm run build:web
```

Арт попадёт только в `apps/web/src/dev/bobek-v2`. После сборки можно открыть `/__look-prototype`, выбрать **«Новий Бобек V2»**, сменить одежду и эмоцию, затем включить QA-предпросмотр и проверить обычные экраны.

## Принципиальные ограничения
- **Это иллюстративный арт-прототип.** Он более плоский и не настолько плюшевый, как требуемый эталон из `assets/beaver/front.webp`; нельзя без приёмки выдавать его за готового персонажа.
- Это всё ещё набор **композитных поз**, а не полный профессиональный скелет (например, голова/пальцы/глаза как независимые кости). Для сложных анимаций необходима дополнительная работа над ригом.
- QA сохраняется только в localStorage: настоящая серверная экипировка и покупки не изменены. Обычная production-модель остаётся прежней.
- Одежда не готова для всех 32 товаров; отсутствуют дополнительные ракурсы. Фоны с `bakedBobek` и статичная карта не меняются.
- Репозиторий не содержит арта из ZIP, пока его не импортируют и не пересоберут staging. На staging нет опубликованной финальной модели.

## Следующее художественное задание
Принять **только геометрию / контракт рендера** (1024 квадрат с альфой, одинаковые координаты, слои и позы). Перерисовать мордочку Бобека по утверждённому эталону, сделать мягкую шерсть, премиальное 2.5D освещение, уточнить лапы, рукава, стыки костюмов. Не менять лицо или пропорции в каждом состоянии. После этого заменить только художественные исходники SVG/изображения, повторить импорт и QA. Проверить экспорт в 256px и отображение в Telegram iOS/Android.
