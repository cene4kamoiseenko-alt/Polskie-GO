# Допустимые порядки слов при сборке предложения

У польского свободный порядок слов, поэтому «Poproszę wodę i hot doga» верно так же, как «Poproszę hot doga i wodę». Раньше сборка засчитывалась только при полном совпадении с эталоном.

## Как это работает

- Ответ шага «build» в миссиях и задания BUILD_SENTENCE / WORD_ORDER в уроках проверяются по списку: эталон + варианты автора (`accept` / `alternatives`) + допустимые порядки из таблицы.
- Таблица — `packages/shared/src/orderVariants.ts` (`specList`), одна на миссии и уроки. Ключ — сам ответ (регистр и знаки препинания не важны). База данных и файлы уроков не меняются, правка вступает в силу с деплоем сервера.
- Все слова ответа обязательны: ни одного не пропустить и лишнего не добавить. Перестановкой смысл и формы слов не меняются — переставляются только целые части.

## Запись

```
['Poproszę hot doga i wodę', ['Poproszę [hot doga] i [wodę]', '[Hot doga] i [wodę] poproszę']],
['Grasz na gitarze',          ['(Czy) [grasz na gitarze]']],
['W niedzielę idziemy na mecz Arki', ['{W niedzielę} {idziemy na mecz Arki}', 'Idziemy [w niedzielę] [na mecz Arki]']],
```

| Знак | Что значит |
|---|---|
| `[часть]` | части в `[ ]` меняются местами друг с другом; каждая остаётся цельной, слова между ними (`i`, `jest`) на месте |
| `{часть}` | второй, независимый набор (для случая, когда нужны две перестановки сразу) |
| `<часть>` | третий набор |
| `(слово)` | слово можно не ставить (в варианте без него его просто нет) |

Несколько записей у одного ответа объединяются. На одну запись не больше 48 вариантов.

## Чего в таблице быть не должно

Перестановок, которые меняют смысл: порядок действий («iść prosto i skręcić w lewo»), «вчера холоднее, чем сегодня», «Dla Ani kupię…» ↔ «Ania kupi…». Если сомневаетесь — записи нет, проверяется только эталон.

## Что проверяют тесты

`packages/shared/test/order-variants.test.ts`: каждая запись раскрывается в перестановки слов ответа без потерь и добавлений (необязательные — только из скобок); `apps/server/test/order-variants.test.ts`: у каждой записи есть задание, все варианты собираются из плашек, неверная перестановка отклоняется. Браузер — `scripts/order-build-check.ts`.

## Обратная связь

`diagnoseOrder` разбирает неверный ответ по словам: неверная форма («woda» вместо «wodę») — тогда показывается пояснение шага (падеж); верные слова в другом порядке — «слова выбраны правильно, но порядок не подходит»; не все слова — «не хватает слов». Пояснение падежа при верных формах не выдаётся.
