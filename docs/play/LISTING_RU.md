## 4. Формы Play Console (ответы-заготовки)

### Data safety (безопасность данных)

| Тип данных (по Google) | Собирается | Передаётся третьим лицам | Зачем | Примечание |
|---|---|---|---|---|
| Имя | да (из Telegram; в гостевом аккаунте нет) | нет | функции приложения, аккаунт | можно задать своё имя в профиле |
| Идентификаторы пользователя | да (id Telegram или случайный номер гостя) | нет | функции приложения, аккаунт | |
| Действия в приложении (прогресс, ответы, настройки) | да | нет | функции приложения, аналитика внутри игры | |
| Покупки (записи о платежах Stars) | да, только в Telegram-версии | нет | функции приложения, учёт | данные карт не собираются |
| Аудио (запись голоса в упражнении) | отправляется на проверку, **не хранится** | поставщик распознавания речи как обработчик (Azure / Google, если включено) | функции приложения | пометить как «обрабатывается эпизодически» (ephemeral) — сверить определение в форме |
| Журналы сбоев / диагностика | да, без имени и идентификаторов | нет | стабильность | хранится 30 дней |

- Данные шифруются при передаче (HTTPS): **да**.
- Можно запросить удаление данных: **да** — в приложении (Профиль → Настройки → Удалить аккаунт) и по ссылке `/delete-account`.
- Рекламный идентификатор не используется. Данные не продаются.

### Content rating (IARC)

Приложение образовательное: насилия, азартных игр, откровенного и пугающего содержания нет; пользовательского контента нет (имя бобра и имя в профиле — короткие поля, видимые друзьям по коду и в рейтинге, если игрок сам включил). Ожидаемый возраст — для всех. Анкету заполняет владелец, отвечая «нет» на вопросы о насилии, сексуальном контенте, лексике, наркотиках, азартных играх; «да» — только на «пользователи могут общаться / делиться именами» (друзья и рейтинг без чата).

### Целевая аудитория и контент

- Целевой возраст: **13+** (приложение не для детей до 13 лет). Участие в программе «Для семей» не заявляется.
- Приложение не новостное, не для здоровья, не финансовое, не госприложение.

### Разрешения

Приложение-оболочка запрашивает только доступ в интернет. Микрофон запрашивает сам браузер Chrome при первом упражнении на произношение (разрешение сайта). Уведомления Android не используются (напоминания идут через Telegram-бота).
