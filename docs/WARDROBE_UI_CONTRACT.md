## Контракт данных

- `GET /api/shop` → `{ balance, premium, items: ShopItem[] }`. Поля вещи: `id`, `slug`, `slot`, `name`, `assetKey`, `price`, `rarity`, `isPremium`, `rewardOnly`, `city`, `unlock`, `owned`, `equipped`, `visualStatus`.
- `visualStatus`: `ready` (есть слои), `legacy-whole-look` (цельный костюм), `not-wearable` (домик), `pending` и `unknown` (слоя нет: за Złotki не продаётся, во владении надевается, Бобек его не рисует).
- Идентичность вещи для образа — `assetKey` (`toLookItemId(assetKey)` — id в ядре). «item_ids» рендерера — это `equipmentFromWear(outfit.wear)`.
- Сохранение: `POST /api/inventory/equip { itemId, equipped }`. Покупка: `POST /api/shop/buy { itemId }`, ошибки: `reward_only`, `already_owned`, `visual_pending` (409), `premium_required`, нехватка Złotki.
- Примерка: `tryOn(wear, assetKey)` → `{ after, removed, candidateVisible, candidateReason }`; «Снимет: …» на панели — те же `removed`, что вычислит сервер.

## Что заменить, когда появится рендерер слоёв (точки замены, больше ничего менять не нужно)

1. **`ItemArt` в `Shop.tsx`**: ветка `COSTUME → costumeAsset()` (цельные картинки) и ветка `WEAR_SLOTS → BeaverPart` (значок). Для вещей со статусом `ready` вместо значка показать миниатюру слоя вещи (`lookAssetUrl(key, width)` из `apps/web/src/lib/assets.ts`); значок остаётся для `pending` и `unknown`.
2. **`costumeCard`**: `costumeScene()` / `travellerScene()` — картинки сцен цельных костюмов. Уходят вместе со статусом `legacy-whole-look`, когда костюмы станут слоями; сцена карточки тогда рисуется `BeaverLook` по `tryOn`.
3. Сервер, вкладки, карточки, панель действия, правила конфликтов — без изменений.

Пока слоёв нет: 0 вещей `ready`, 7 цельных костюмов `legacy-whole-look`, остальная одежда `pending` (каталог — `assets/wardrobe/WARDROBE_CATALOG.json`). Это не дефект экрана: экран честно показывает «Визуал готовится» и не продаёт такие вещи.

## Найдено при проверке и исправлено

- **Панель действия на 320 px**: в один ряд название вещи резалось под кнопкой («Джинс…»), метка «Визуал готовится» и «Снимет: …» налезали на кнопку. Теперь два ряда: вещь, пометки и «×» сверху, кнопка действия на всю ширину снизу.
- **Кнопка «отменить примерку»**: 36×36 px, меньше зоны касания 40 px; стала 44×44.
- **Название костюма «Путешественник»** на 320 px обрезалось краем карточки; включены перенос и переносы слов.
- Нижний отступ страницы увеличен (`pb-56`): последняя карточка прокручивается выше более высокой панели.
