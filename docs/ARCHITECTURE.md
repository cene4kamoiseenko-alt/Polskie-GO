# POLSKI GO — архитектура продукта

## 1. Принципы

* **Сервер — единственный источник правды.** Правильные ответы никогда не уходят клиенту до проверки;
  XP, Złotki, прогресс, покупки и Premium рассчитываются и записываются только на сервере.
* **Идемпотентность.** Каждая награда имеет уникальный ключ (`xp_events.idempotency_key`,
  `wallet_transactions.idempotency_key`, `user_quests(user, quest, period)`, `payment_events.charge_id`) —
  повторный запрос ничего не начисляет.
* **Модульный монолит, API-first.** Один Fastify-сервис с чёткими модулями (`services/*`), без
  микросервисов. REST API готов для будущих клиентов iOS/Android/web.
* **Контент — данные.** Города, маршруты, уроки, вправы, слова, квесты, предметы и тарифы лежат в БД и
  редактируются в админке без изменения кода. Исходный контент — типизированный DSL в `apps/server/src/content`.

## 3. Навигация Mini App

Нижнее меню — 5 вкладок, остальное открывается из логичных точек входа (кнопка «Назад» Telegram):

```
Главная ─┬─ Продолжить → Урок → Результаты → (Карта: анимация путешествия)
         ├─ Тренировки: Повторение · Мои ошибки · 5 минут · Быстрый раунд
         ├─ Слово дня → Словарь
         └─ Ещё: Словарь · Rozmowa AI · Egzaminy · Рейтинг · Гардероб · Домик · Дневник · Друзья
Карта ──── Город (шторка) → Уроки города
Обучение ─ Переключатель городов → тропа уроков → Урок / Экзамен города
Квесты ─── Ежедневные · Еженедельные · Сюжетные → Сюжетная сцена
Профиль ── Статистика 7/30/90 · Навыки · Достижения · Гардероб · Домик · Дневник · Настройки → Premium
```

Онбординг (только при первом запуске): привет → язык → уровень → входной тест (опц.) → цель →
время в день → напоминания → карта → первый урок → первые XP → главный экран.

## 4. Дизайн-система

* Палитра из ТЗ: зелёный `#45C486`, светло-зелёный `#DFF6E8`, кремовый `#FFF9ED`, XP `#FFC857`,
  голубой `#69C7F4`, текст `#243746` + польский красный `#E5484D` для акцентов (как на референсе).
* Токены — CSS-переменные; тёмная тема — отдельные значения (`.dark`), а не инверсия.
  Тема берётся из Telegram (`colorScheme`) или выбирается вручную.
* Шрифт Nunito (округлый, кириллица + польская диакритика).
* Компоненты: «3D»-кнопки с нижней тенью, карточки, прогресс-бары, кольцо цели, шторки, модалки,
  тосты, skeleton-загрузка, пустые состояния, экран ошибки, конфетти.
* Безопасные зоны Telegram (`--tg-safe-area-inset-*`, `--tg-content-safe-area-inset-*`),
  `disableVerticalSwipes`, цвет шапки, системная кнопка «Назад» со стеком обработчиков.
* Reduced motion: системная настройка + переключатель в приложении (`MotionConfig`).

## 5. Бобёр Бобек

Оригинальный векторный SVG-персонаж (`components/Beaver.tsx`), 10 состояний: `happy, wave, sad, think,
celebrate, sleep, travel, gift, cheer, surprised` (глаза, брови, рот, эффекты, анимации рук и тела).
Одежда рисуется слоями поверх тела по слотам: шапки, очки, шарфы, куртки, рюкзаки, обувь, аксессуары в лапе,
костюмы (дракон, сирена). Купленный и надетый предмет сразу виден на персонаже — везде в приложении.

Замена на Lottie/Rive: достаточно реализовать тот же интерфейс `<Beaver mood outfit size />`.

## 6. Карта Польши

`components/PolandMap.tsx` — SVG-карта с контуром страны, Вислой, Одрой, Мазурскими озёрами, горами
и лесами по реальным координатам (та же проекция используется сервером для городов: 1000×950).
Города — маркеры с эмодзи-символом, процентом прохождения, замком/галочкой; пройденный путь — красная
линия; бобёр-пин над текущим городом; анимация поезда при переезде. Координаты городов редактируются в админке.

Правила прогресса: первый город открыт; уроки открываются по порядку; экзамен города («босс») — после
`ticket_lessons` уроков; сдача экзамена (≥70%) даёт билет в следующий город, сувениры и костюм города.

## 7. Учебная система

16 типов упражнений: перевод слова (оба направления), перевод предложения, сборка предложения,
пропуск, аудирование, произношение, диалог, пары, поиск ошибки, грамматический конструктор, чтение,
ситуационная игра, слово по картинке, диктант, лишнее слово, порядок слов. «Быстрый раунд» и
«Практический экзамен» — режимы сессии.

Поток сессии: `POST /sessions` (сервер делает снимок вправ с ответами, клиенту — публичная версия) →
`POST /sessions/:id/answer` (проверка, объяснение, SRS, навыки, события квестов) →
`POST /sessions/:id/finish` (порог прохождения, награды, слова, город, квесты, достижения).

* Ошибка → вправа повторяется в конце урока и попадает в «Мои ошибки» (интервальное повторение).
* Слова урока → личный словарь + расписание SM-2. «Изучено» — после 3 успешных повторений подряд.
* Ввод текста терпит регистр, пунктуацию; без диакритики/с одной опечаткой — «почти верно».
* Произношение — распознавание речи устройства (Web Speech API) с честной пометкой, что это не
  фонетическая оценка; можно пропустить без штрафа.
* Уровень польского (A0–B2) повышается **только** экзаменами; входной тест лишь рекомендует старт.

### Анти-накрутка

* Повтор пройденного урока: 25% XP, максимум 2 награждаемых повтора в сутки, без Złotki.
* Тренировки: дневной лимит XP. Не пройденный урок (<50%) — 0 XP.
* Сессия: только владелец, блокировка строки (`FOR UPDATE`), TTL 3 ч, нельзя завершить дважды,
  неполностью или быстрее 1 с на вправу.
* Rate limiting по токену/IP, валидация всех входов (Zod), лимиты размеров.

индексы под горячие запросы (`user_id + created_at`, `user_id + due_at`, `period_key + xp`).

## 9. Безопасность

* Проверка подписи `initData` (HMAC-SHA256, `WebAppData`), срок жизни `auth_date`; сессионный токен HMAC.
* Админка: scrypt-хэши паролей, роли `SUPERADMIN / EDITOR / SUPPORT`, журнал всех изменений.
* Webhook бота защищён `X-Telegram-Bot-Api-Secret-Token`.
* Секреты (бот, AI, сессии) — только на сервере. Dev-вход невозможен при `NODE_ENV=production`.
* Пользователь может экспортировать все свои данные (JSON) и удалить аккаунт (каскадно; платёжный
  журнал обезличивается для бухгалтерии).

## 10. Монетизация (Telegram Stars)

* `MONTH_1` — подписка Stars с автопродлением (`subscription_period = 2592000`, единственный период,
  который поддерживает Telegram); `MONTH_3`, `MONTH_12` — разовые платежи, продлевающие Premium.
* Поток: `createInvoiceLink` → `openInvoice` в Mini App → `pre_checkout_query` (сервер сверяет инвойс,
  пользователя, сумму) → `successful_payment` (идемпотентно по `telegram_payment_charge_id`) → Premium.
  Клиент только ждёт подтверждения сервера.
* Отмена автопродления — `editUserStarSubscription`; Premium действует до конца периода. Возвраты — `refunded_payment`.
* Бесплатными навсегда остаются карта, базовый путь A0–B2, словарь, квесты; Premium — расширенный AI,
  ролевые игры, подготовка к экзамену с AI, премиум-косметика. Złotki не продаются за деньги.

## 11. AI-преподаватель

`services/ai.ts`: системный промпт учитывает подтверждённый уровень и язык объяснений; режимы
разговор / проверка грамматики / объяснение (Free), ролевые игры (кафе, врач, ужонд, собеседование,
аренда, вокзал) и подготовка к экзамену (Premium). Лимиты в день (Free/Premium из админки), месячный
бюджет выходных токенов, учёт токенов в `ai_usage`. Без ключа — честный ограниченный режим со словарём.
