## 2. Доделать до запуска

- [ ] **Сезон «Święta» начинается 1 декабря:** его 3 миссии по 4 минуты и 5–6 шагов, а ноябрьские уже по ~10 минут. Удлинить так же (вторая сцена, `docs/MISSIONS_LONG.md`).
- [ ] **Пропуск месяца пуст с января по июнь 2027:** после «Święta» (декабрь) следующий сезон — «Energylandia» в июле. Нужны сезоны на январь–июнь (хотя бы январь–февраль к запуску).
- [ ] **Невидимые награды:** «7 дней подряд» даёт солнцезащитные очки, «3 города» — рюкзак с картой; у обеих вещей нет картинки, игрок получает то, чего не видно.
  Квест «Квартира в Кракове» даёт ковёр, а интерьер из домика убран; сувениры за экзамены городов (Сирена, дракон, гном) негде посмотреть. Решение: картинки или другие награды; сувениры — в паспорт.
- [ ] **«Костюм проводника» нарисован пилотом** (пакет 2026-11-04). Переименовать в пилота (и, возможно, давать за премиум-миссию «Рейс в Гданьск») или вернуть кондуктора.
- [ ] **Четыре города без уроков:** Lublin, Rzeszów, Kielce, Zakopane (на карте — «уроки готовятся»). Для запуска допустимо; по 8 уроков и экзамен — следующим этапом.
- [ ] **Сцены миссий:** 21 временный кадр с Бобеком в стандартной одежде внутри (образ игрока там не виден), 8 сезонных миссий — векторные заглушки. Нужны фоны без Бобека — `docs/UNFINISHED_ASSETS.md`, раздел 3.
- [ ] Временные панорамы Жешува и Закопане; 5 картинок бота — там же.

## 3. Функции, которых не хватает

- [ ] **«Сообщить об ошибке в задании»** в уроке: на старте игроки найдут ошибки в польском, а сейчас о них не узнать (админка видит только задания с высоким процентом ошибок).
- [ ] **Сбор ошибок клиента:** падение экрана у игрока нигде не записывается. Нужны приёмник на сервере, таблица и раздел в админке.
- [ ] **Воронка в админке:** онбординг → первый урок → второй день. Сейчас есть регистрации, удержание D1/D7, сложные задания.
- [ ] **Политика конфиденциальности:** своей страницы нет (есть условия Premium и `/terms`, экспорт и удаление данных). По умолчанию действует стандартная политика Telegram для ботов и Mini Apps;
  для игроков из ЕС лучше своя короткая страница: что храним, сколько и как удалить.
