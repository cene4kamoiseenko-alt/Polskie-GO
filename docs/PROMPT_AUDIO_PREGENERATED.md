# Задание владельца 2026-10-28 (дословно)

POLSKI GO — ОТКЛЮЧИТЬ ПЛАТНУЮ ГЕНЕРАЦИЮ ПРИ ПРОСЛУШИВАНИИ

СРОЧНАЯ ЗАДАЧА: перевести всю озвучку POLSKI GO в режим PRE-GENERATED AUDIO ONLY.

Обязательное правило: ни один обычный пользователь не должен запускать генерацию ElevenLabs при прослушивании слова, урока, миссии или словаря.

1. Отключи генерацию по требованию

Найди все существующие вызовы ElevenLabs в клиенте и сервере.

* Убери обращение к ElevenLabs из обработчиков кнопок воспроизведения.
* Отключи автоматическую генерацию при отсутствии аудио в R2.
* Удали повторную генерацию при открытии урока.
* Запрети TTS fallback на сервере и в браузере, включая speechSynthesis.
* Не удаляй существующие качественные аудиофайлы.
* Не удаляй Secret ELEVENLABS_API_KEY.

2. Реализуй воспроизведение только готовых MP3

Используй существующий Audio Manifest с 4741 уникальной аудиоединицей.

Каждое слово, фраза или диалог должны ссылаться на готовый аудиофайл.

Логика:

1. Пользователь нажимает динамик.
2. Приложение определяет audio_id.
3. Получает готовый MP3 через Worker из Cloudflare R2.
4. Воспроизводит файл.
5. При повторном нажатии воспроизводит тот же файл.

Запрос к ElevenLabs при этом категорически запрещён.

Если файла нет, показывай «Озвучка скоро появится» или делай кнопку недоступной.

Не подменяй отсутствие MP3 женским голосом, синтезатором устройства или новой генерацией.

3. Настрой Cloudflare R2

Проверь существующий R2 bucket и binding, используй их повторно.

Реализуй выдачу MP3 через Worker с правильными HTTP-заголовками, кэшированием и поддержкой Range-запросов для мобильного воспроизведения.

Не делай весь R2 bucket публичным без необходимости.

Используй версионированные имена файлов, чтобы при изменении озвучки старые файлы не смешивались с новыми.

4. Административная генерация

Создай отдельный защищённый инструмент для владельца приложения.

Только администратор сможет:

* Выбирать готовые слова и фразы для генерации.
* Выбирать мужской голос Kamil.
* Смотреть, сколько кредитов потребуется.
* Запускать генерацию после подтверждения.
* Сохранять готовые MP3 в R2.
* Просматривать очередь и ошибки генерации.

Никаких открытых пользовательских API для генерации произвольного текста.

Добавь настройку AUDIO_GENERATION_MODE=admin_only и реализуй её проверку в серверном коде. Простое создание переменной без соответствующей логики недостаточно.

5. Не генерируй одинаковое аудио повторно

Перед генерацией проверяй наличие готового MP3 с нужным текстом, голосом, моделью и настройками.

Если файл уже готов, возвращай его.

Добавь защиту от одновременных генераций и журнал расходов.

6. Исправь голос

Установи выбранный Kamil как основной голос польского контента.

Перед генерацией проверь его voice_id через доступный API ElevenLabs.

Старые женские MP3 не удаляй до создания мужских замен, но не используй их в режиме Kamil.

7. Тестирование — обязательно

Проверь следующее:

* Первое воспроизведение готового MP3 — 0 новых запросов к ElevenLabs.
* 20 повторных воспроизведений — 0 новых запросов.
* Повторное открытие приложения — 0 новых запросов.
* Прослушивание одного слова в разных миссиях — тот же MP3.
* Отсутствующий MP3 — 0 запросов ElevenLabs.
* Обычный пользователь не может получить доступ к административной генерации.
* Все тесты и TypeScript проходят.

Проверь отдельно на iOS Safari, Android и Telegram Mini App.

8. Отчёт

После внедрения сообщи:

* Какие файлы изменены.
* Какой R2 bucket используется.
* Сколько MP3 уже сохранено.
* Какой процент каталога озвучен.
* Сколько слов пока без аудио.
* Какой voice_id установлен.
* Подтверждено ли отсутствие новых платных генераций при воспроизведении.

Не запускай массовую генерацию без моего разрешения.

Главный критерий готовности: нажатие кнопки динамика никогда не вызывает ElevenLabs API.

После тестирования подготовь изменения к публикации в Production Worker polskie-go.
