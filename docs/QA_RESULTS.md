### Серверные тесты доступа к экзамену (`legacy-exam-access.test.ts`)

- Warszawa после расширения: доступ к экзамену сохраняется, сессия экзамена 200.
- Kraków: доступ сохраняется.
- Частичный прогресс 5 из 6: экзамен закрыт (403), шестой урок доступен.
- Łódź: старые уроки до расширения открывают экзамен, после — нет.
- Повторное прохождение не меняет `firstCompletedAt`, счётчик прохождений 2.

Тесты Варшавы и Кракова падают на прежней логике (воспроизведено до исправления).

## Не проверено

- Ручной чек-лист Telegram iOS/Android (`docs/MANUAL_QA_TELEGRAM.md`): не пройден, нет устройства.
- `npm run a11y`, `npm run screens`, `npm run perf`: после изменений этого этапа не запускались.
- Состояние загрузки «Сегодня»: нет ни одной проверки.
- Полный офлайн-переход `goto('/')`: не проверен. В сценарии страница открыта на `/map`, затем сеть выключается и переход делается кликом.
- Настройка профиля «Меньше анимаций» для императивных анимаций (`animate()`, бесконечные циклы): отдельного e2e нет. В сценарии A4 эмулируется системный `prefers-reduced-motion`.
- Касание и жесты в реальном Telegram WebView на iOS и Android.
- Деплой Cloudflare и seed на D1 production: результат отсюда не виден.
- Раскрытие секретов автоматически: не проверено.
