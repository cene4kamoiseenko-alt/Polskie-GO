## Итерация 2 — единая модель Бобека (в работе)

- Решение владельца: везде живописный 2.5D Бобек по доске, одежда меняется слоями. Векторный риг отклонён.
- Переходный режим (решение владельца): живопись везде уже сейчас; готовые растровые костюмы работают сразу; вещи без живописного слоя не рисуются, в гардеробе пометка «скоро»; купленное не теряется.
- Платный API генерации (OpenAI) владелец отменил: всё бесплатно. Новые живописные слои появляются только из листов, которые владелец генерирует сам вне репозитория. Пайплайн в репозитории — импорт: шаблон листа и промпты для владельца, вырезка однотонного фона без нейросетей, нарезка, выравнивание по якорям, WebP, манифест, контактный лист.
- Векторный черновик ADR-005 (отклонён) не закоммичен. Из него стоит сохранить: резолвер образа `resolveLook`/`tryOn`, провайдер образа, запрет ручных подмен, DOM-контракт `data-look`, исправление невидимого бобра на карте, серверный тест каталога, e2e «один образ на всех экранах».
- Агенты архитектуры и QA остановлены владельцем. Новые запуски — только по его команде.
