## Этап 1 — живописный Бобек (ADR-005)

- Решение: живописная «бумажная кукла» на холсте 1024 с якорями; голова и морда только из базы; одежда — слои; цельные костюмы — `legacy-whole-look` на переходный период; вещь без живописного слоя (`pending`) не рисуется и не продаётся. Полный текст — `docs/ADR-005-PAINTERLY-BEAVER.md`.
- Ядро `packages/shared/src/look`: `resolveLook`, `tryOn` (не сохраняет), `equip`/`unequip` с вытеснением по слотам, `canPurchase` (`visual-pending`), DOM-контракт `data-look-*`, проверка манифеста, список недостающих ассетов. Подключено: сервер — M3 (`2a30c6e`, ADR-007), web — M1 (`apps/web/src/lib/look.ts`, `components/Beaver.tsx`: `Beaver` = образ из профиля, `BeaverLook` = готовый ResolvedLook для примерки и галереи; векторного тела Бобека больше нет).
- Платный API генерации не используется. Живописные слои появляются только из листов владельца. Нужны листы для эталона 1 (база спереди в двух позах, худи PL, кепка, рюкзак, кеды — 18 частей) и эталона 2 (бариста, повар — 8 частей); список — ADR-005, раздел о недостающих ассетах.
- Вопросы владельцу — ADR-005, §18: 6, 8, 9 ждут ответа.
