## Итерация 2 — единая модель Бобека (в работе)

- Решение владельца: везде живописный 2.5D Бобек по доске, одежда меняется слоями. Векторный риг отклонён.
- Переходный режим (решение владельца): живопись везде уже сейчас; готовые растровые костюмы работают сразу; вещи без живописного слоя не рисуются, в гардеробе пометка «скоро»; купленное не теряется.
- Слои генерирует API OpenAI. Ключ — секрет окружения `OPENAI_API_KEY`, в сети разрешён `api.openai.com`. Ключ доступен только в новой сессии: в этой пишется код и пайплайн, генерация — в следующей.
- Архитектор переписывает ADR-005 и план. После него параллельно: «персонаж» (компоновщик слоёв, единый образ), «экраны», «пайплайн ассетов».
