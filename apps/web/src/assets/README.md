# Растрові ассети POLSKI GO

Покладіть сюди готові ілюстрації — застосунок автоматично використає їх замість векторних.
Формат: WebP (або PNG) з прозорим фоном, без тексту на зображенні.

| Папка | Файли | Розмір |
|---|---|---|
| `beaver/` | `happy, wave, sad, think, celebrate, sleep, travel, gift, cheer, surprised, read, learn, royal, wait` | 800×940, персонаж по центру, ноги внизу |
| `cities/` | `<slug міста>.webp`, напр. `warszawa`, `krakow`, `wroclaw` | 1200×600, панорама |
| `icons/` | `home, map, lessons, dictionary, ai, grammar, quests, exam, profile, premium, rewards, settings, wardrobe, …` | 256×256 |

Одяг на растровому бобрі не накладається: для гардеробу залишається векторний Бобек,
поки не буде набору растрових шарів одягу.
