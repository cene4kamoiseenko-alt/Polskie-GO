# POLSKI GO — прогресс

Ветка: `claude/polski-go-telegram-app-r8helf` (в `main` не пушим). Cloudflare собирает приложение из этой ветки (см. README).
Файл обновляется перед каждым крупным шагом и перед сжатием контекста. После сжатия — продолжать с первого незакрытого пункта.

## Требования, которые нельзя терять
- Не подменять польский голос чужим языком; не выдавать фиктивную оценку произношения; ошибка микрофона или сервера
  не блокирует курс; без награды за непроверенное произношение.
- Исправлять код и данные, а не только писать отчёт. Не объявлять курс проверенным по выборке.
- БД: стабильные ID, exact-match обновления (exercise-fixes / continuation-fixes / LESSON_MOVES / TEXT_FIXES в seed.ts),
  без сброса, без закрытия городов, с учётом правок из админки и прогресса пользователей.
- Один правильный ответ; «найди лишнее» только с явным критерием; повторы (точные, смысловые, перестановки) запрещены;
  не больше трёх одинаковых механик подряд.
- Не включать платные сервисы, не делать реальных списаний, не печатать секреты. Не утверждать, что проверено на iPhone,
  в Telegram, на реальном микрофоне или у провайдера, если этого не было.
- Объём не сокращать молча: удаление/перенос заданий — в docs/CONTENT_AUDIT_RU.md с причиной и судьбой прогресса.
- Подтверждение владельца — только для разрушающих решений (сокращение Кракова, тема, формат транскрипции).
- После каждого шага зелёные: `npm test`, `npm run typecheck`, `node --import tsx scripts/content-lint.ts`.

## Замеры
- `npm run perf`, одна машина, по 3 прогона «до» (e8733e8) и «после»; «готово» — нет заставки и ни одного скелетона:
  холодный старт 2390–2632 → 2112–2237 мс; повторное открытие 1075–1156 → 944–1018 мс; вкладка «Карта» после паузы
  580–654 → 438–496 мс; остальные вкладки в пределах шума; «Профиль» ≈ 950 мс в обеих версиях (три запроса, самый
  долгий был `/api/achievements` — 489 мс в Miniflare; после пакетирования метрик 403 → 310 мс на метриках).
  Это headless Chromium на сервере, не телефон: цифры для сравнения «до/после».
- Главный чанк web: 621.8 kB → 610.4 kB (заставка) → 322.8 kB (LazyMotion + чанки react 166 kB / query 40 kB).
  Стартовый JS gzip: 190 → 165 kB; возможности framer-motion — отдельный чанк 57 kB после старта.
- Контраст: axe 0 нарушений на 11 экранах в обеих темах; пиксельная проверка 0 реальных провалов.
- Тесты: shared 105/105, server 116/116 (19 файлов), e2e 21 проверка, a11y 30 проверок, content-lint 1494 задания, 14 миссий.
- Баланс городов (scripts/city-balance.ts): Warszawa 26 уроков / 499; Łódź 5 / 57; Kraków 41 / 744; Katowice 5 / 58;
  Opole 5 / 56; Wrocław 5 / 53.
