## Требования, которые нельзя терять
- Исправлять код и данные, а не только писать отчёт. Не объявлять курс проверенным по выборке.
- Голос: не подменять польский голос русским/английским; не выдавать фиктивную оценку произношения;
  отказ микрофона/ошибка сервера не блокирует курс; без награды за непроверенное произношение.
- «Найди лишнее» — только с явным критерием; если критерий спорный — другая механика.
- Один правильный ответ — остальные варианты неверны именно в контексте (не «тоже подходит, но менее вежливо»).
- Переводы/ввод/сборка — принимать корректные синонимы, формы и порядок слов.
- Повторы: точные, смысловые, перестановки вариантов, одна фраза без новой цели, длинные серии одной механики.
  Удалённое заменять качественным упражнением, объём не сокращать молча.
- БД: стабильные ID, exact-match обновления, без сброса, без закрытия городов, учёт прогресса и правок админки.
- Не включать платные сервисы, не делать реальных списаний, не печатать секреты. Не утверждать проверку на iPhone/в Telegram без доступа.
