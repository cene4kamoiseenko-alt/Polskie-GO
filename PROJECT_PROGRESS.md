## Требования, которые нельзя терять
- Исправлять код и данные, а не только писать отчёт. Не объявлять курс проверенным по выборке.
- Голос: не подменять польский голос русским/английским; не выдавать фиктивную оценку произношения;
  отказ микрофона/ошибка сервера не блокирует курс; без награды за непроверенное произношение.
- «Найди лишнее» — только с явным критерием; если критерий спорный — другая механика.
- Один правильный ответ — остальные варианты неверны именно в контексте (не «тоже подходит, но менее вежливо»).
- Переводы/ввод/сборка — принимать корректные синонимы, формы и порядок слов.
- Повторы: точные, смысловые, перестановки вариантов, одна фраза без новой цели, длинные серии одной механики.
  Удалённое заменять качественным упражнением, объём не сокращать молча.
- БД: стабильные ID, exact-match обновления, без сброса, без закрытия городов, учёт прогресса и правок админки.
- Не включать платные сервисы, не делать реальных списаний, не печатать секреты. Не утверждать проверку на iPhone/в Telegram без доступа.

## План
1. [в работе] Разбор ZIP: патч применён к рабочей копии; проверить тесты/typecheck/сборку, оценить каждое изменение, оставить/откатить.
2. Подключить присланные изображения (бобр: машет/радуется/читает; панорамы Кракова и Вроцлава) вместо/рядом с ассетами из ZIP.
3. Голос — аудирование: найти причину, исправить воспроизведение (TTS сервер → кеш → клиент, медленная скорость, повтор, стоп при переходе, ошибки, один звук за раз).
4. Голос — произношение: микрофон, запись, отправка, распознавание, честный результат, обход без награды.
5. Выгрузка всех упражнений (города, миссии, экзамены, вход. тест, диалоги, словарь) в таблицы для ревью.
6. Автопроверки: дубликаты (точные/смысловые/перестановки), «лишнее» без критерия, пересечение вариантов, пустые поля, переводы, аудио/картинки, серии механик.
7. Языковая проверка по городам: Warszawa → Łódź → Kraków → Katowice → Opole → Wrocław → экзамены/миссии/словарь. Журнал правок с до/после.
8. Обновление БД: расширить реестр exact-match исправлений, проверить на локальной D1 со старыми данными.
9. Проверка ответов: регистр/пробелы/пунктуация/диакритика/опечатки; тесты.
10. Тесты, typecheck, сборка, браузер (урок с разными механиками, аудирование, произношение), итоговый отчёт.
